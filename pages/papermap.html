4. 建议的读法给你的顺序

若目标是补产业链中上游 + 建立完整技术判断，建议这个顺序：
  1. 先搭骨架：把 keon/awesome-physical-ai 的目录结构读一遍。它的分类（骨干 / VLA 架构 / 动作表征 / 世界模型 / 推理 / 学习范式 / 部署 / 安全）就是一份领域地图，比读十篇论文更省时间。
  2. 读四篇定海神针：RT-1 → RT-2 → Diffusion Policy → π₀。这四篇串起来，VLA 的主干你就有了。
  3. 补李飞飞这条线：VoxPoser → ReKep → BEHAVIOR-1K → 2026 世界模型分类。她的价值不在单点技术，在问题定义的演进。
  4. 补产业侧：NVIDIA Cosmos + Isaac-GR00T 两个仓库的 README 和文档。这两个是投资岗真正的语言——别人跟你聊的是这些，不是 arXiv。
  5. BCI 单独走：先读 Willett 2023 Nature 打底，再读 2026 Nature Medicine 那篇看临床落地，最后看 brain2qwerty 的代码。
两个提醒：
① 不要平均用力。60 篇里真正决定你能不能跟人聊的，是最上面那 10 篇 8 分以上的。剩下的当作字典，用到再查。
② 清单仓库会过时。Awesome-Robotics-Foundation-Models（2024-10 停更）和 haoranD/Awesome-Embodied-AI（2025-06 停更）这两个别当主入口—— 它们内容还行，但已经缺了 2025-2026 一整年的进展，包括 WAM 和具身 CoT 这两个现在最热的方向。
