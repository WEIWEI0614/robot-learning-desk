RL 基础：从策略梯度到信赖域

论文精读

为什么按这个顺序读：TRPO 解决步长与单调改进的冲突 → A3C 用异步并行破样本相关性 → DDPG 把 DQN 的离散动作推广到连续 → MPC 跳出策略学习、直接在线规划。四篇构成一条清晰的「怎么把 RL 用在连续控制上」的路线。

演进线索
策略梯度的方差问题 → 信赖域约束 → 样本效率 → 连续动作处理 → 在线重规划

VLA 演进：视觉-语言-动作怎么融合

产业链底层

为什么按这个顺序读：RT-2 把动作离散化成 token 复用 LLM → OpenVLA 证明开源小模型也能做，并解决动作离散化的精度损失 → ALOHA 用 ACT 做低成本双臂遥操作 → Mobile ALOHA 把它推到动态场景。这是最需要优先掌握的一簇。
