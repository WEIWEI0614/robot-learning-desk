五、日常怎么用（省 token 的关键）

你想做的事怎么做成本
系统梳理一簇打开对应「簇复盘」课件，逐页看讲解 + 做测验 + 玩交互组件0（离线）
复习某个概念课件翻到对应场景；或问 DeepTutor（KB 已挂好，只检索 facts）0 / $0.003
自测课件里的阶段测验 → 不会的再用 DeepTutor 苏格拉底引导0 / $0.003
交互理解概念打开「概念交互演示」，拖滑块看参数对行为的影响0（离线）
通勤听音频audio_overview 脚本环节已验证可用，只差配 TTS（见风险表）待配 TTS
找新论文 / 看脉络切到「论文地图」页签：李飞飞脉络 + 43 个高星仓库实测星数 + 脑机接口高分论文0（离线）
加新论文把论文丢进 pdfs/ → 跑 gen_facts.py → prepare_kb.py → 建 KB → make_lesson.py~$0.03
为什么这套流程省 token：每篇论文只解析一次→ facts（3-5K tokens，压缩到原文 ~15%）；此后出题、答疑、生成课件只引用 facts，不碰原文；RAG 检索替代全文直塞（每轮 4-8K 而非 40-60K）；产物全部离线化，复习零成本。
