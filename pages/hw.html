1 · 基础概念扫盲

下面这 10 个词，是你读任何机器人教程都会遇到的。先过一遍，后面就不卡了。

1.1 什么是"开源机器人"

"开源"在硬件领域要分两层看，很多人在这里被坑：

层次含义例子
硬件开源3D 打印文件、电路板设计、物料清单（BOM）全部公开，你可以自己造一台SO-101、Open Duck Mini（可自造）
软件开源只有控制代码、训练代码、模型权重公开，硬件你得买成品Microduck 鸭子（硬件不开源）
这是最容易误解的一点。Hugging Face 的 Microduck（399 美元那只鸭子）软件是 Apache-2.0 开源的，但 Pollen Robotics 明确表示没有开源硬件的计划。想自己造鸭子，得看 apirrone/Open_Duck_Mini（约 3.4k star，目标 BOM <$400）；想直接有台能改的成品，才买 Microduck。

1.2 自由度（DoF）与关节命名

一个自由度 = 一个能独立运动的关节轴。SO-101 是 6 自由度机械臂，意思是它有 6 个转动关节，从底座到夹爪依次是：

顺序关节名通俗理解
1shoulder_pan整条手臂左右转（像人转身）
2shoulder_lift大臂上下抬（像人抬胳膊）
3elbow_flex手肘弯
4wrist_flex手腕上下掰
5wrist_roll手腕自转
6gripper夹爪开合

没有第 7 个关节（比如人的小指那样的末端），是因为便宜的舵机机械臂做不出灵巧手。6 个自由度已经能完成"抓起来放进盒子里"这类任务，这已经足够跑通整条学习闭环。

1.3 舵机是什么

舵机（servo）就是"带位置反馈的电机"。它和普通电机最大的区别是：你告诉它"转到 90 度"，它自己闭环控制转到 90 度并保持住，而不是你给它通电它就一直转。

每个关节一个舵机。SO-101 用的是 Feetech STS3215——一款带串行总线接口的数字舵机，能回读角度、温度、负载。

1.4 减速比（1/345 是什么意思）

电机本身转得快但没劲。舵机内部有一组齿轮把转速降下来、把扭矩放大，这个比例就是减速比。

关键理解：1/345 表示"减速比 345 : 1"。电机转 345 圈，输出轴才转 1 圈。
代价是变慢，收益是扭矩放大 345 倍（还要乘齿轮效率，实际约 70–80%）。

所以 1/345 是最"有劲"的、1/147 是最"灵活"的。哪个关节需要劲，哪个关节就用大减速比——这就是下面 leader 臂配不同减速比的全部原因。

1.5 为什么 leader 臂和 follower 臂用不同的舵机

SO-101 是双臂系统：一条 leader（主臂，人手拖着动）+ 一条 follower（从臂，复现动作）。

臂职责选型逻辑
leader人手直接握着自己动要轻、好推——推力太大，人拖着累且记不准位置
follower复现 leader 的动作，去干活要有劲——要真抓东西、抗重力，所以全部用 1/345

leader 的配比是：shoulder_lift 用 1/345（要扛住整条手臂自重）、shoulder_pan 和 elbow_flex 用 1/191（折中）、wrist_flex/wrist_roll/gripper 用 1/147（末端轻，要灵活）。

这里有一个我核实时遇到的来源矛盾，顺手讲清楚。有一篇英文报道写"leader arm employs three motors with different ratios"（leader 用三个舵机）。我按这句去数，会觉得 leader 只有 3 个舵机。但对照商品 BOM：1× 1/345 + 2× 1/191 + 3× 1/147 = 6——正好 6 个。所以正确读法是"leader 用了三种不同减速比"，不是"三个舵机"。这类句子在转述时很容易被传歪。

1.6 总线舵机 vs 普通 PWM 舵机

这决定了你的接线方式，也是新手最容易接错的地方。

普通 PWM 舵机总线舵机（SO-101 用的）
接线每个舵机一根信号线，接到控制器不同引脚所有舵机串成一条线（菊花链），只有 3 根线：电源、地、数据
识别方式靠物理引脚区分靠每个舵机自己的 ID（1–6）区分
通信单向往舵机发脉冲半双工串口，一根线双向收发，能回读角度/温度/负载
为什么必须给每个舵机写唯一 ID：所有舵机通过同一根数据线接收指令，指令里带"这是给 3 号舵机的"。出厂时每个舵机的 ID 都是 1——如果不改，你发一条"1 号转到 90 度"，六个舵机会一起转，机器要么卡死要么把自己拧坏。ID 写进舵机的 EEPROM，掉电不丢，写一次就行。

另外注意：连接电脑和舵机的是总线适配板（MotorBus / Waveshare 板），不是直接 USB 线。

一个能省几小时调试的细节：用 Waveshare 控制板时，两个跳线都要打到 channel B（USB）。打错的表现是电脑死活找不到串口，而你会怀疑驱动、怀疑线、怀疑舵机。

1.7 为什么要"校准"（这是最容易被跳过、后果最严重的一步）

校准要解决两个问题：

  • 零位：舵机内部的"0 度"和机械结构的"正前方"对不上。校准就是告诉系统"现在这个物理姿态，记作角度 0"。
  • 量程：每个关节能安全转动的上下限。不知道量程，程序就可能把关节往机械限位上撞。
为什么它和 AI 学习直接相关：神经网络策略学的是"在这个位置该输出什么数值"。如果两台机器人的零位定义不一样，同一套策略换一台机器就完全失效——因为它以为的"90 度"是另一处物理位置。这就是为什么官方文档说"校准对迁移学习是必需的"。
还有一条：拆装过任何关节之后，必须重新校准。

1.8 遥操作（teleoperation）是什么

人操作 leader 臂，系统实时读取 leader 各关节角度，转成指令发给 follower 臂，follower 复现同样姿态。这是采集演示数据的标准方式——比用键盘/程序控制自然得多，因为人手演示的动作本身就是"正确做法"。

1.9 模仿学习，以及"为什么至少 50 条演示"

模仿学习（Imitation Learning / Behavior Cloning）的思路很直白：让机器人看人怎么做的，然后照做。常见算法是 ACT 或扩散策略（Diffusion Policy）。

数据量为什么是 50 条起：一次演示只覆盖一种物体位置和一种操作轨迹。神经网络要从少数样本里学到"任务本质"很难，它更容易记住"这次物体在这、手往那走"。演示数量不足 → 换一个物体位置就失败。所以官方建议每个任务至少 50 条，并且刻意改变物体位置和朝向。

1.10 BOM 是什么

Bill of Materials，物料清单。开源硬件项目的 BOM 就是"你要买什么、买几个、什么规格"的完整列表。SO-101 的 BOM 由 Hugging Face 维护在 LeRobot 文档和 SO-ARM100 仓库里。

2 · 选型判断：为什么是 SO-101，不是鸭子

维度SO-101 机械臂Open Duck Mini 双足鸭
成本¥880 单臂 / ¥1,700 双臂实际 BOM $500–650（≈¥3,600–4,700，不是宣传的 $400）
舵机数量6（单臂）14–16 + 2 个微型舵机
技术难点运动学 + 数据采集双足平衡 + sim2real 全栈最难的部分
官方文档完整装配指南 + BOM + 预排 STL有 print guide / assembly guide，社区在完善中
训练生态LeRobot 原生支持，MuJoCo 模型现成，ACT 半小时出策略MuJoCo Playground + PPO，要训步态
失败代价摔了不会坏，装错重装跌倒可能损坏结构件和舵机
我的判断：先用 SO-101 跑通一次完整闭环，再做鸭子。
不是因为鸭子不好，而是因为你没跑通过一次"硬件 → 数据 → 训练 → 真机部署"的完整链路之前，鸭子的难度会让你把大量时间花在调试上，而不是学习上。SO-101 用 1/4 的成本给你同样的完整闭环，而且每一步都有官方文档兜底。
鸭子适合在你已经知道 sim2real 的坑在哪之后再做——那时你才配得上它的难度。

4 · 装配步骤

① 打量规验打印机→ ② 打印全部结构件→ ③ 舵机写 ID→ ④ 装舵机走线→ ⑤ 菊花链接线→ ⑥ 固定底座通电→ ⑦ 校准→ ⑧ 单臂测试→ ⑨ 双臂遥操作→ ⑩ 采数据

总耗时约 3–4 小时（不含打印）。

阶段一：打印前（别跳过）

① 先打 STL/Gauges/ 里的量规，对着 STS3215 舵机或乐高块试装
为什么：如果打印机有尺寸偏差（挤出过量/不足、收缩），直接打整臂会得到一堆装不进去的零件。量规只花 10 分钟，能省 16 小时和一整卷料。过紧或过松就调切片缩放再打一次。
② 打印全部结构件
按上表参数。优先用仓库里预排好的单文件 STL（已经帮你排好版，不用自己摆件）。

阶段二：舵机准备

③ 给每个舵机写唯一 ID 和统一波特率
为什么：出厂全是 ID=1。写进 EEPROM，掉电不丢，一辈子写一次——除非你把舵机拆到别的机器人上用。
ID 必须按物理位置固定：底座=1 ... 夹爪=6。写错了意味着程序以为在动 1 号关节，实际动的是 5 号，机器会做出完全无法理解的动作。
实操上：只连夹爪电机，确认 ID 设为 6，再依次往前做 wrist_roll……

阶段三：机械装配

④ 舵机装进连杆壳体，线缆穿过打印的走线槽
为什么强调走线：关节转动会反复拉扯线缆。走线槽是为了让线在转动时留出余量，否则几十次动作后线就断了，还很难查。
⑤ 菊花链接线，ID 1（底座）→ 6（夹爪）
按 ID 顺序串接。总线是共享的，但接线顺序影响走线美观和线缆受力。
⑥ 把底座夹到桌面再通电
为什么：6 关节同时运动时反作用力很大，没固定的底座会直接翻倒或甩出去，可能砸坏夹爪。官方文档把这一步列为通电前强制项。
通电时手远离工作空间，急停方式就是直接拔 USB 线。

阶段四：校准与首次运动

⑦ 校准（最关键的一步）
按提示把手臂移动到整个运动范围的各个位置，系统记录每个关节的零位和量程。
拆装过关节 → 必须重新校准。
⑧ 单臂通电测试，然后 ⑨ 双臂遥操作
先只连 follower，验证 6 个关节都响应、无跳变、夹爪能全行程开合、没有线缆在某个姿态下被卡住。确认无误再接 leader。
⑩ 采数据
每任务 ≥50 条，刻意变化物体位置和朝向，给任务起有意义的名字。

5 · 上手命令

先装 LeRobot（[feetech] 会带上 Feetech 舵机 SDK）：

pip install "lerobot[feetech]"

然后按顺序执行：

# 1. 找到手臂的串口（运行后按提示插拔 USB）
lerobot-find-port
#   macOS 典型值：/dev/tty.usbmodem*  或  /dev/tty.usbserial-*
#   Linux  典型值：/dev/ttyACM0（或 CH340 适配器的 ttyUSB0）

# 2. 逐个写舵机 ID 与波特率
lerobot-setup-motors --robot.type=so101_follower --robot.port=/dev/tty.usbmodemXXXX

# 3. 校准 follower
lerobot-calibrate --robot.type=so101_follower \
  --robot.port=/dev/tty.usbmodemXXXX --robot.id=my_follower

# 4. 校准 leader
lerobot-calibrate --teleop.type=so101_leader \
  --teleop.port=/dev/tty.usbmodemYYYY --teleop.id=my_leader

# 5. 双臂遥操作
lerobot-teleoperate --robot.type=so101 --robot.port=/dev/tty.usbmodemXXXX \
  --teleop.type=so101_leader --teleop.port=/dev/tty.usbmodemYYYY

# 6. 采数据（带摄像头）
lerobot-record --robot.type=so101 --robot.port=/dev/tty.usbmodemXXXX \
  --robot.cameras.top.type=opencv --robot.cameras.top.index=0 \
  --dataset.repo_id=你的名字/so101-pick-cube --dataset.single_task="pick cube"
关于命令的版本差异：网上有些教程（包括我查到的中文页面）用的是旧版脚本路径 python lerobot/scripts/calibrate.py。新版 LeRobot 统一成了 lerobot-calibrate 这类 CLI 命令。两套现在都能跑，但别混着抄。
Linux 用户额外一步：串口在 /dev/ttyACM*，需要把用户加进 dialout 组：sudo usermod -aG dialout $USER，然后注销重登（或 newgrp dialout）。macOS 不需要这一步，但要装 CH340 驱动。

6 · 我是怎么核实这些信息的

你问过我"你怎么操作的"。这一节就是答案——不是装饰，它决定了上面的数字可不可信。

6.1 我查了什么，为什么交叉验证

来源提供什么可信度判断
Hugging Face LeRobot 官方文档BOM、装配指南、命令最高——出问题它负责
TheRobotStudio 的 SO-ARM100 仓库STL 文件、3DPRINT.md高——硬件设计方
Silicon Valley Robotics Center 的 SO-101 中文页分步流程、切片参数、打印机型中高——工程向整理，步骤详细
商品页（ThinkRobotics 等）精确到货号的舵机配比（C018/C001/C044/C046）中——商业来源，但货号具体，交叉得起来

为什么必须三四个来源对齐：单一来源的信息在转述时会变形。上面 1.5 节那个"three motors / 三种减速比"就是活例子——若只看一篇英文报道，我会给出一份错的 BOM。

6.2 我明确没有核实的东西（诚实标注）

  • 国内渠道的实际价格与兼容性。淘宝/AliExpress 的 STS3215 约 ¥100/个，比官方 $23 便宜不少，但我没有实测过它的固件版本和 ID 写入工具是否与 LeRobot 兼容。这是省钱的最大不确定项。
  • 我没有实物。装配步骤来自官方文档与工程整理，我没有亲手装过，所以"手感类"的坑（哪颗螺丝难拧、哪个件容易断）我给不出来。
  • 打印时长 8–16 小时是社区口径，实际高度依赖切片参数和机器。
成本口径需要提醒：不同来源给出的"臂成本"不完全一致——有写 follower $121.94、有写 $123，差异来自汇率和采购时点。我采用 ≈$122 / ≈$230 这一组（2026 年 9 月美国 BOM 口径）。你不是美国采购，实际落地价要用国内渠道重算——这些数字只能当量级参考。

7 · 装完之后能干什么

立刻能做的四件事

  • 遥操作：人手拖着 leader，follower 精确复现——这是后面所有训练的数据来源。
  • 采数据集并上传 Hugging Face Hub：数据格式是社区标准，可以直接被别人复用。
  • 训一个 ACT 或 Diffusion Policy：50 条演示，消费级硬件半小时出策略，让机械臂学会"捡方块放进盒子"。
