先说清楚一件事：这五样的共同点是——它们是"语言"，不是"难题"。你不需要更深的数学，你需要把这层符号系统过一遍。过完之后，所有机器人学论文对你就是可读的。别把它当成补课，当成学一门方言。

一、五个缺口

① SE(3) / so(3)、指数映射、伴随表示

旋转不能相加
位姿插值必须走李代数；四元数只是其中一个参数化。R₁·R₂ 是新的旋转，但 R₁+R₂ 什么都不是——所以"在旋转之间做平均/插值/优化"这件事必须换到切空间上做。
👉 Sola《A micro Lie theory》原文（17 页，最小充分集）｜ MLS 第 2 章原文

② 旋量、twist / wrench、雅可比的几何构造

教材默认你会
机器人学的速度级运动学全用这套记号。关键认知：雅可比是用运动旋量逐列拼出来的，不是对正向运动学求导。这个区别决定了你能否手推一个从没见过的构型。
👉 MLS 第 2 章（旋量 / twist / wrench / 伴随）｜ §3.4 雅可比

③ 最优控制 / 轨迹优化的 KKT 与信赖域实现

接触导致非凸
不是"懂最优化"就行。真实难点是：接触序列让问题变成非凸的组合–连续混合问题，必须分层求解——先定接触模式，再在模式内做连续优化。
👉 Posa《刚体接触轨迹优化直接法》IJRR（22 页）

④ 卡尔曼滤波的推导与可观性

要能自己推
不是调 filterpy。Barfoot 从三个不同角度推导卡尔曼滤波（MAP / 贝叶斯推断 / 增益优化），再讲存在唯一性与可观性——这一节是"能自己推"和"会用库"的分水岭。
👉 Barfoot §3.1.4 / §3.2 / §3.3.2–3.3.7（卡尔曼三推导 + 可观性）｜ Sola 四元数与 ESKF（95 页）

⑤ 接触动力学的互补问题（LCP / NCP）

变分不等式
仿真里穿模、抖动的根源在这。接触是单边约束 + 库仑摩擦锥，写成 0 ≤ φ ⊥ λ ≥ 0 这种互补条件——它不是 ODE，是变分不等式，求解器完全不同。
👉 Posa IJRR（LCP → MPCC → SQP，互补约束如何进优化）｜ 含碰撞与摩擦的稳定性分析（SOS 李雅普诺夫）

二、阅读顺序（约一周）

  1. 第 1–3 天建立记号：《微李理论》17 页 → MLS 第 2 章 → MLS 第 3.4 节雅可比。别一上来啃 MLS，先用 Sola 那 17 页把符号系统建立起来。
  2. 第 4–6 天估计与滤波：Barfoot §3.3.2–3.3.7（卡尔曼三推导 + 可观性）→《四元数运动学与 ESKF》。后者是机器人区别于通用滤波的地方。
  3. 第 7 天接触与优化：Posa 论文。搞清互补约束怎么进优化、为什么需要松弛、为什么分层。
