题目 1点击展开解答 ▾

本章约定：

  • {s} 是 fixed frame / space frame，固定在空间中。
  • {b} 是 body frame，但它不是动力学中随刚体一起旋转的非惯性运动 frame，而是瞬时与运动刚体固连 frame 重合的静止 frame。

因此，{b} 的“body”含义是：在某一瞬时，它与刚体固连坐标系重合，用来描述刚体当前姿态；但本书把它当作 stationary/inertial frame 来处理。也就是说，{b} 不是一个随时间连续旋转的非惯性参考系，而是在每个瞬时选取的、与刚体当前姿态重合的静止参考系。

刚体位姿写作

\[

(R,p),\qquad R=[\hat{x}_b\ \hat{y}_b\ \hat{z}_b]\in SO(3),\quad p\in\mathbb{R}^3,

\]

齐次变换为

\[

T=\begin{bmatrix}R&p\\0&1\end{bmatrix}\in SE(3).

\]

如果把 {b} 误解为随刚体旋转的非惯性运动 frame，就会把本章的 twist

\[

V=S\dot{\theta}=(\omega,v)

\]

误解释为“在旋转非惯性系中测得的量”，从而混淆空间速度与物体速度的变换关系；也会把 wrench

\[

F=(m,f)

\]

误认为是在非惯性系中定义的力旋量。本章的事实底座明确要求：所有 frames 都是 stationary, inertial frames，因此 twist 与 wrench 的代数变换必须按静止 frame 之间的坐标变换理解，而不是按动力学非惯性系理解。

题目 2点击展开解答 ▾

本章定义：

\[

SO(3)=\{R\in\mathbb{R}^{3\times 3}\mid R^T R=I,\ \det R=1\}.

\]

类似地，

\[

SO(2)=\{R\in\mathbb{R}^{2\times 2}\mid R^T R=I,\ \det R=1\}.

\]

仅有

\[

R^T R=I

\]

时，矩阵的列向量是单位正交列。对 3×3 矩阵取行列式：

\[

\det(R^T R)=\det(I)=1.

\]

又因为

\[

\det(R^T R)=(\det R)^2,

\]

所以

\[

(\det R)^2=1,

\]

即

\[

\det R=\pm 1.

\]

因此，R^T R=I 只保证 \det R=1 或 \det R=-1。其中 \det R=1 对应右手系，\det R=-1 对应左手系。本章要求所有 frames 都是右手系，满足

\[

\hat{x}\times\hat{y}=\hat{z},

\]

所以必须额外加上

\[

\det R=1

\]

来排除左手系。

加上 \det R=1 后，连续独立变量数目不改变。因为 \det R=\pm 1 是一个离散的二选一条件；在已经满足 R^T R=I 的连通分支中，\det R 的符号不能连续变化。\det R=1 只是从两个分支中选出一个分支，并不额外减少连续自由度。因此 SO(3) 仍然是三维的。

题目 3点击展开解答 ▾

本章给出：

  • 绕 fixed-frame 轴旋转：

\[

R_{sb'}=R R_{sb}.

\]

  • 绕 body-frame 轴旋转：

\[

R_{sb''}=R_{sb} R.

\]

解释如下。

R_{sb} 的列向量是 {b} 的三个单位轴在 {s} 中的表示：

\[

R_{sb}=[\hat{x}_b\ \hat{y}_b\ \hat{z}_b].

\]

若绕 fixed-frame 轴旋转 {b}，则旋转作用在 {s} 中表达的所有 body 轴上。于是新的 body 轴为

\[

\hat{x}_{b'}=R\hat{x}_b,\quad

\hat{y}_{b'}=R\hat{y}_b,\quad

\hat{z}_{b'}=R\hat{z}_b.

\]

因此

\[

R_{sb'}=[R\hat{x}_b\ R\hat{y}_b\ R\hat{z}_b]

=R[\hat{x}_b\ \hat{y}_b\ \hat{z}_b]

=R R_{sb}.

\]

所以是左乘。

若绕 body-frame 轴旋转 {b}，则旋转轴是在 {b} 自身坐标中表达的。此时旋转矩阵 R 作用在 body frame 的局部坐标上，等价于在 R_{sb} 的右侧相乘：

\[

R_{sb''}=R_{sb} R.

\]

因此，fixed-frame 旋转对应左乘，body-frame 旋转对应右乘。二者一般不可交换：

\[

R R_{sb}\neq R_{sb} R.

\]

题目 4点击展开解答 ▾

[\hat{\omega}] 是单位轴 \hat{\omega} 对应的 skew-symmetric matrix，满足

\[

[\omega]x=\omega\times x.

\]

当 \omega=\hat{\omega} 为单位向量时，[\hat{\omega}] 满足

\[

[\hat{\omega}]^T=-[\hat{\omega}].

\]

它把叉乘运算写成矩阵乘法。

Rodrigues 公式为

\[

\operatorname{Rot}(\hat{\omega},\theta)

=e^{[\hat{\omega}]\theta}

=I+\sin\theta[\hat{\omega}]

+(1-\cos\theta)[\hat{\omega}]^2.

\]

因为

\[

\sin(-\theta)=-\sin\theta,\qquad

1-\cos(-\theta)=1-\cos\theta,

\]

并且

\[

[-\hat{\omega}]=-[\hat{\omega}],

\]

所以

\[

\operatorname{Rot}(-\hat{\omega},-\theta)

=I+\sin(-\theta)[-\hat{\omega}]

+(1-\cos(-\theta))[-\hat{\omega}]^2.

\]

计算：

\[

\sin(-\theta)[-\hat{\omega}]

=(-\sin\theta)(-[\hat{\omega}])

=\sin\theta[\hat{\omega}],

\]

而

\[

[-\hat{\omega}]^2

=(-[\hat{\omega}])^2

=[\hat{\omega}]^2.

\]

因此

\[

\operatorname{Rot}(-\hat{\omega},-\theta)

=I+\sin\theta[\hat{\omega}]

+(1-\cos\theta)[\hat{\omega}]^2

=\operatorname{Rot}(\hat{\omega},\theta).

\]

这表示绕轴 \hat{\omega} 转 \theta，等价于绕相反轴 -\hat{\omega} 转 -\theta。

若 \theta=0，则

\[

\sin 0=0,\qquad 1-\cos 0=0,

\]

所以

\[

\operatorname{Rot}(\hat{\omega},0)=I.

\]

即不旋转时得到单位矩阵。

题目 5点击展开解答 ▾

在平面中，screw axis 写作

\[

S=(\omega,v_x,v_y).

\]

其中 \omega 是角速度分量，(v_x,v_y) 是线速度分量。对于平面刚体运动，twist 为

\[

V=S\dot{\theta}.

\]

它表示沿 screw axis S 以角速度 \dot{\theta} 运动时的空间速度。

S\theta 是 exponential coordinates。它表示绕 screw axis S 转过角度 \theta 的有限位移参数。沿 S 以速度 \dot{\theta} 运动单位时间，等价于绕 S 转 \theta。因此

\[

V=S\dot{\theta}

\]

是瞬时速度，而

\[

S\theta

\]

是有限位移的指数坐标。

本例中

\[

S=(1,2,0),\qquad \theta=\frac{\pi}{2}.

\]

因此

\[

S\theta

=

\left(1\cdot\frac{\pi}{2},\ 2\cdot\frac{\pi}{2},\ 0\cdot\frac{\pi}{2}\right)

=

\left(\frac{\pi}{2},\pi,0\right).

\]

下面用 Python 验证：

import math

S = (1, 2, 0)
theta = math.pi / 2

S_theta = tuple(s * theta for s in S)
print(S_theta)
print(S_theta[0] == math.pi / 2)
print(S_theta[1] == math.pi)
print(S_theta[2] == 0)

预期观察：

(1.5707963267948966, 3.141592653589793, 0.0)
True
True
True

即

\[

S\theta=(\pi/2,\pi,0).

\]

本例中

\[

\beta=90^\circ=\frac{\pi}{2}.

\]

而

\[

\theta=\frac{\pi}{2}.

\]

因此二者一致。\beta 是 screw coordinates 中给出的旋转角，\theta 是沿 screw axis 走的指数坐标角度；在这个例子里它们都等于 90^\circ，即 \pi/2。
