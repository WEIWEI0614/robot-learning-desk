题目 1点击展开解答 ▾

误差定义：本章统一采用

\[

\theta_e(t)=\theta_d(t)-\theta(t),

\]

其中 $\theta_d(t)$ 为期望关节位置，$\theta(t)$ 为实际关节位置。注意符号方向是「期望减实际」，不是反过来。

误差动力学的核心地位：本章把任务规格转换为执行器力/力矩或速度指令，核心思路是用反馈构造期望的误差动力学。也就是说，控制器设计的目标不是直接指定 $\theta(t)$，而是让误差 $\theta_e(t)$ 满足某个微分方程，例如一阶形式

\[

\dot\theta_e+\frac{1}{\tau}\theta_e=0

\]

或二阶标准形式

\[

\ddot\theta_e+2\zeta\omega_n\dot\theta_e+\omega_n^2\theta_e=0.

\]

通过选择增益（如 $K_p,K_i,K_d$）来配置该误差方程的根，从而决定误差是否趋零、收敛多快、是否振荡。

三个性能指标：本章用以下三个指标描述误差响应：

  • steady-state error $e_{ss}$：稳态误差；
  • overshoot：超调量；
  • 2% settling time：误差进入并保持在终值 $\pm 2\%$ 范围内所需时间。

这三个指标分别对应「最终准不准」「过程冲不冲」「收敛快不快」。

题目 2点击展开解答 ▾

速度输入 P 控制：控制律为

\[

\dot\theta=K_p\theta_e.

\]

当参考为 setpoint 时，$\dot\theta_d=0$，由 $\theta_e=\theta_d-\theta$ 得

\[

\dot\theta_e=\dot\theta_d-\dot\theta=-K_p\theta_e,

\]

即

\[

\dot\theta_e+K_p\theta_e=0.

\]

这是一阶误差动力学，时间常数 $\tau=1/K_p$，误差指数收敛到零。

恒速参考下的 P 控制：设 $\dot\theta_d=c$，则

\[

\dot\theta_e=\dot\theta_d-\dot\theta=c-K_p\theta_e,

\]

即

\[

\dot\theta_e+K_p\theta_e=c.

\]

稳态时 $\dot\theta_e=0$，得

\[

e_{ss}=\frac{c}{K_p}.

\]

因此 P 控制对恒速参考存在非零稳态误差，且 $K_p$ 越大误差越小，但不能消除。

速度输入 PI 控制：控制律为

\[

\dot\theta=K_p\theta_e+K_i\int_0^t\theta_e\,dt.

\]

对恒速参考 $\dot\theta_d=c$，有

\[

\dot\theta_e=c-K_p\theta_e-K_i\int_0^t\theta_e\,dt.

\]

对时间求导：

\[

\ddot\theta_e=-K_p\dot\theta_e-K_i\theta_e,

\]

即

\[

\ddot\theta_e+K_p\dot\theta_e+K_i\theta_e=0.

\]

这是二阶误差动力学，其标准形为

\[

\ddot\theta_e+2\zeta\omega_n\dot\theta_e+\omega_n^2\theta_e=0,

\]

对应

\[

\omega_n=\sqrt{K_i},\qquad \zeta=\frac{K_p}{2\sqrt{K_i}}.

\]

只要 $K_p>0,K_i>0$，特征根实部为负，误差收敛到零，因此恒速参考下 $e_{ss}=0$。

PI 能消除恒速参考稳态误差的原因：积分项 $\int_0^t\theta_e\,dt$ 会持续累积误差。若存在非零稳态误差，积分项将不断增大，从而改变控制输入，直到误差被驱动到零。P 控制没有这种「记忆」，恒速参考下必须保留一个非零误差才能产生足够的 $\dot\theta$ 来匹配 $c$。

若 $\dot\theta_d$ 不是常数：原书明确指出，PI 对恒速参考可零稳态误差，但若 $\dot\theta_d$ 不是常数，PI 不能保证完全消除稳态误差。因为积分项只能消除常值偏差，对时变参考需要更高阶或前馈补偿。

题目 3点击展开解答 ▾

推导误差微分方程：由

\[

\dot\theta=\dot\theta_d+K_p\theta_e+K_i\int_0^t\theta_e\,dt

\]

以及 $\theta_e=\theta_d-\theta$，得

\[

\dot\theta_e=\dot\theta_d-\dot\theta

=\dot\theta_d-\left(\dot\theta_d+K_p\theta_e+K_i\int_0^t\theta_e\,dt\right)

=-K_p\theta_e-K_i\int_0^t\theta_e\,dt.

\]

对时间求导：

\[

\ddot\theta_e=-K_p\dot\theta_e-K_i\theta_e,

\]

即

\[

\ddot\theta_e+K_p\dot\theta_e+K_i\theta_e=0.

\]

标准二阶形式为

\[

\ddot\theta_e+2\zeta\omega_n\dot\theta_e+\omega_n^2\theta_e=0,

\]

因此

\[

\omega_n=\sqrt{K_i},\qquad \zeta=\frac{K_p}{2\sqrt{K_i}}.

\]

前馈项 $\dot\theta_d$ 的作用：前馈项直接提供期望速度，使控制器不需要仅靠反馈来「追赶」参考速度。对恒速参考，前馈项已经提供了正确的稳态速度，PI 只需消除初始误差和扰动，因此可以做到零稳态误差。前馈+PI 是本章推荐的首选速度控制律。

数值计算：已知 $K_p=20$，$K_i=100$。

\[

\omega_n=\sqrt{100}=10,\qquad

\zeta=\frac{20}{2\sqrt{100}}=\frac{20}{20}=1.

\]

因为 $\zeta=1$，系统是 critically damped。

2% settling time 为

\[

t_s=\frac{4}{\zeta\omega_n}=\frac{4}{1\times 10}=0.4\ \text{s}.

\]

这与原书 PI 速度控制例子中 $K_i=100$ 时根 $s_{1,2}=-10=-K_p/2$、critically damped、2% settling time $0.4$ s 一致。

题目 4点击展开解答 ▾

正确的任务空间误差：本章定义

\[

[X_e]=\log(X^{-1}X_d),

\]

其中 $X_e\in\mathbb{R}^6$ 是该 twist 的向量表示。$X_e$ 不是 $X_d-X$，而是使 $X$ 单位时间到 $X_d$ 的 twist。SE(3) 元素不能相减，因此必须用群运算 $\log$ 和 $X^{-1}X_d$ 来构造误差。

任务空间速度控制律：完整形式为

\[

V_b(t)=\mathrm{Ad}_{X^{-1}X_d}V_d(t)+K_pX_e(t)+K_i\int_0^t X_e(t)\,dt,

\]

其中 $[X_e]=\log(X^{-1}X_d)$，然后

\[

\dot\theta=J_b^\dagger(\theta)V_b.

\]

这里 $V_b$ 是 body twist，$V_d$ 是期望 twist，$\mathrm{Ad}_{X^{-1}X_d}$ 把期望 twist 转换到当前 body frame。

为什么要经过 $J_b^\dagger(\theta)$：任务空间控制律直接给出的是末端 body twist $V_b$，但机器人执行器接受的是关节速度 $\dot\theta$。body Jacobian 满足

\[

V_b=J_b(\theta)\dot\theta.

\]

因此需要从 $V_b$ 反解 $\dot\theta$。当 $J_b$ 为方阵且可逆时，$\dot\theta=J_b^{-1}V_b$；当机器人冗余或非方阵时，用伪逆

\[

\dot\theta=J_b^\dagger(\theta)V_b

\]

得到最小范数解。

奇异情形：若 $J_b(\theta)$ 在某配置下奇异，$J_b^{-1}$ 不存在，但 Moore-Penrose 伪逆 $J_b^\dagger$ 仍然存在（只要 $J_b$ 不是零矩阵）。伪逆可以通过 SVD 构造，对奇异值取倒数时对零奇异值取零。因此 $\dot\theta=J_b^\dagger V_b$ 仍然可以计算，但此时某些任务空间方向不可实现，实际末端 twist 会丢失奇异方向分量。原书在本章使用 $J_b^\dagger(\theta)$ 作为一般形式，并未要求 $J_b$ 始终满秩。

题目 5点击展开解答 ▾

computed torque 控制律各项作用：

\[

\tau=M(\theta)\left(\ddot\theta_d+K_p\theta_e+K_i\int\theta_e(t)\,dt+K_d\dot\theta_e\right)+\tilde h(\theta,\dot\theta).

\]

  • $M(\theta)$：质量矩阵，用于把期望的关节加速度转换为力矩；
  • $\ddot\theta_d$：期望加速度前馈；
  • $K_p\theta_e$：位置误差比例反馈；
  • $K_i\int\theta_e\,dt$：积分反馈，消除稳态误差；
  • $K_d\dot\theta_e$：速度误差微分反馈，提供阻尼；
  • $\tilde h(\theta,\dot\theta)$：模型非线性项（Coriolis、重力等），用于补偿机器人自身动力学。

为什么能消去非线性项：机器人动力学一般形式为

\[

M(\theta)\ddot\theta+\tilde h(\theta,\dot\theta)=\tau.

\]

将 computed torque 控制律代入，得

\[

M(\theta)\ddot\theta+\tilde h

=M(\theta)\left(\ddot\theta_d+K_p\theta_e+K_i\int\theta_e\,dt+K_d\dot\theta_e\right)+\tilde h.

\]

两边消去 $\tilde h$，再左乘 $M^{-1}(\theta)$，得

\[

\ddot\theta=\ddot\theta_d+K_p\theta_e+K_i\int\theta_e\,dt+K_d\dot\theta_e.

\]

由 $\theta_e=\theta_d-\theta$，有 $\ddot\theta_e=\ddot\theta_d-\ddot\theta$，因此

\[

\ddot\theta_e+K_d\dot\theta_e+K_p\theta_e+K_i\int\theta_e\,dt=0.

\]

非线性项被精确消去，误差动力学变成线性二阶（或三阶）系统，增益可以按标准二阶响应设计。

PD + gravity compensation：若忽略积分项和模型误差，且重力模型完美，本章给出的控制律为

\[

\tau=K_p\theta_e+K_d\dot\theta+\tilde g(\theta).

\]

注意这里速度项写的是 $\dot\theta$ 而非 $\dot\theta_e$，因为在 setpoint 控制中 $\dot\theta_d=0$，所以 $\dot\theta_e=-\dot\theta$，符号吸收进增益后形式一致。该控制律由 Krasovskii-LaSalle 定理得到全局收敛。

Python 伪代码验证 2% settling time：

import numpy as np
import matplotlib.pyplot as plt

# 一阶误差动力学: dtheta_e/dt = -Kp * theta_e
Kp = 10.0
tau = 1.0 / Kp
theta_e0 = 1.0
dt = 0.001
T = 1.0
t = np.arange(0, T, dt)
theta_e = np.zeros_like(t)
theta_e[0] = theta_e0

for i in range(1, len(t)):
    dtheta_e = -Kp * theta_e[i-1]
    theta_e[i] = theta_e[i-1] + dtheta_e * dt

# 找到 2% settling time
threshold = 0.02 * abs(theta_e0)
settling_idx = np.where(np.abs(theta_e) < threshold)[0]
if len(settling_idx) > 0:
    t_s = t[settling_idx[0]]
else:
    t_s = None

print(f"Kp = {Kp}, tau = {tau:.4f} s")
print(f"理论 2% settling time ≈ 4/Kp = {4/Kp:.4f} s")
print(f"数值 2% settling time = {t_s:.4f} s")

plt.plot(t, theta_e)
plt.axhline(threshold, color='r', linestyle='--')
plt.axhline(-threshold, color='r', linestyle='--')
plt.xlabel('t (s)')
plt.ylabel('theta_e')
plt.title('First-order error dynamics')
plt.grid(True)
plt.show()

预期观察：当 $K_p=10$ 时，$\tau=0.1$ s，理论 2% settling time 约为 $4/K_p=0.4$ s。数值模拟应给出接近 $0.4$ s 的结果，误差曲线从 $1$ 指数衰减，进入 $\pm 0.02$ 带内后不再超出。这验证了本章一阶误差响应中 $t_s\approx 4\tau=4/K_p$ 的结论。
