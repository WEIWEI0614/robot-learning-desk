题目 1.点击展开解答 ▾

第 1 步：回顾 Puma 560 的关节轴几何关系。

Puma 560 是经典的 6 自由度串联操作臂，其 DH 参数（原书第 7 章）决定了各关节轴 $z_0,\dots,z_5$ 的方向。关键事实是：Puma 560 的肩部（$q_1$）绕竖直轴 $z_0$ 旋转，而 $q_2$（肩）与 $q_3$（肘）的轴线在名义位形下是互相平行的——它们都垂直于 $z_0$ 且彼此平行（这是 Puma 类"肘型"操作臂的典型特征，$q_2$ 与 $q_3$ 的轴线都沿同一方向，即 $z_1 \parallel z_2$）。

第 2 步：分析 $q_1$ 旋转对轴方向的影响。

$q_1$ 绕 $z_0$ 旋转时，会把 $z_1$、$z_2$ 整体绕竖直轴转动，但不会改变 $z_1$ 与 $z_2$ 之间的平行关系。因此无论 $q_1$ 取何值，$z_1 \parallel z_2$ 始终成立。

第 3 步：寻找第三个与它们平行的轴。

腕部三个关节 $q_4,q_5,q_6$ 构成球腕：$z_3$（前臂轴）、$z_4$、$z_5$ 在腕心处交于一点。其中 $z_3$ 是前臂的旋转轴，方向由 $q_2+q_3$ 决定。

  • 当 $q_3 = 0$ 时，前臂与上臂共线，此时 $z_3$ 与 $z_1,z_2$ 平行（三者同向）。
  • 更一般地，$z_3$ 的方向由 $q_2+q_3$ 的累积转角决定；只要让 $q_2+q_3$ 使前臂轴与上臂轴平行，即可实现 $z_1 \parallel z_2 \parallel z_3$。

第 4 步：给出一个具体位形。

取 $q_3 = 0$（肘完全伸直），则上臂轴 $z_1$、$z_2$ 与前臂轴 $z_3$ 三者互相平行。此时 $q_1$ 可取任意值（例如 $q_1=0$），$q_2$ 也可取任意值（例如 $q_2=0$），因为 $q_2$ 只改变这些平行轴在平面内的朝向，不破坏平行性。

因此一个满足条件的位形是：

$$\mathbf{q} = [0,\ 0,\ 0,\ q_4,\ q_5,\ q_6]^T$$

其中 $q_4,q_5,q_6$ 任意（腕部姿态不影响 $z_1,z_2,z_3$ 的平行关系）。

第 5 步：与本章奇异性的联系。

当三个关节轴平行时，雅可比 $\mathbf{J}(\mathbf{q})$ 中对应这三列会线性相关（它们对末端速度的贡献方向退化），导致 $\det(\mathbf{J})=0$，即奇异。这正是原书 [PDF p.177–178] 中 Puma ready pose $\mathbf{q}_r$ 出现 $\mathrm{rank}(\mathbf{J})=5$、jsingu 报告 "q6 depends on q4" 的同类现象——轴平行/共面是产生奇异的重要几何来源。

注：原书未给出该具体位形的数值雅可比，此处按符号推导；若需数值验证，可用 p560.jacob0([0 0 0 0 0 0]) 检查其秩。

关键点

  • Puma 560 中 $q_2$ 与 $q_3$ 的轴线天然平行，$q_1$ 的旋转不破坏这一平行关系。
  • 令 $q_3=0$（肘伸直）即可使前臂轴 $z_3$ 也加入平行族，得到 $z_1 \parallel z_2 \parallel z_3$。
  • 三个关节轴平行 ⇒ 雅可比对应列线性相关 ⇒ $\det(\mathbf{J})=0$，机器人处于奇异位形。
  • 这类"轴平行/共面"奇异与腕部 gimbal lock 同属几何奇异，是本章奇异分析的核心例子。
  • 验证方法：用 jacob0 计算该位形的雅可比并检查其秩是否小于 6。

出处

题目 2.点击展开解答 ▾

第 1 步：明确目标与已知关系。

本章把几何雅可比 $\mathbf{J}(\mathbf{q})$ 的角速度部分 $\boldsymbol\omega$ 替换为姿态参数（RPY 或 Euler 角）的速率 $\dot{\boldsymbol\phi}$，得到解析雅可比。对 Euler 角情形，目标是求出矩阵 $\mathbf{B}$，使

$$\boldsymbol\omega = \mathbf{B}\,\dot{\boldsymbol\phi},\qquad \boldsymbol\phi=(\phi_1,\phi_2,\phi_3)$$

其中 $\boldsymbol\phi$ 为 Euler 角（ZYZ 约定），$\mathbf{B}$ 由 Toolbox 的 eul2jac 给出。做法与 RPY 情形完全平行：写出 $\dot{\mathbf{R}}$，代入第 3 章 Eq. 3.4，再解出 $\boldsymbol\omega$。

第 2 步：写出 Euler 角下的旋转矩阵及其导数。

ZYZ Euler 角约定为

$$\mathbf{R}=\mathbf{R}_z(\phi_1)\,\mathbf{R}_y(\phi_2)\,\mathbf{R}_z(\phi_3)$$

对时间求导，用乘积法则：

$$\dot{\mathbf{R}}=\dot{\mathbf{R}}_z(\phi_1)\mathbf{R}_y(\phi_2)\mathbf{R}_z(\phi_3)+\mathbf{R}_z(\phi_1)\dot{\mathbf{R}}_y(\phi_2)\mathbf{R}_z(\phi_3)+\mathbf{R}_z(\phi_1)\mathbf{R}_y(\phi_2)\dot{\mathbf{R}}_z(\phi_3)$$

第 3 步：用第 3 章 Eq. 3.4 把 $\dot{\mathbf{R}}$ 转成角速度。

第 3 章给出 $\dot{\mathbf{R}}\mathbf{R}^T=\mathbf{S}(\boldsymbol\omega)$，即 $\boldsymbol\omega=\mathrm{vex}\!\left(\dot{\mathbf{R}}\mathbf{R}^T\right)$。逐项计算：

  • 第一项：$\dot{\mathbf{R}}_z(\phi_1)\mathbf{R}_y\mathbf{R}_z\cdot(\mathbf{R}_z\mathbf{R}_y\mathbf{R}_z)^T=\dot{\mathbf{R}}_z\mathbf{R}_z^T=\mathbf{S}([0,0,\dot\phi_1]^T)$。因为 $\dot{\mathbf{R}}_z\mathbf{R}_z^T$ 只含绕 $z$ 轴的角速度，且 $\mathbf{R}_y\mathbf{R}_z(\mathbf{R}_y\mathbf{R}_z)^T=\mathbf{I}$。
  • 第二项：$\mathbf{R}_z\dot{\mathbf{R}}_y\mathbf{R}_z\cdot(\mathbf{R}_z\mathbf{R}_y\mathbf{R}_z)^T=\mathbf{R}_z\dot{\mathbf{R}}_y\mathbf{R}_y^T\mathbf{R}_z^T=\mathbf{R}_z\,\mathbf{S}([0,\dot\phi_2,0]^T)\,\mathbf{R}_z^T=\mathbf{S}\!\left(\mathbf{R}_z[0,\dot\phi_2,0]^T\right)$。这里用了相似变换 $\mathbf{R}\mathbf{S}(\mathbf{x})\mathbf{R}^T=\mathbf{S}(\mathbf{R}\mathbf{x})$。
  • 第三项：$\mathbf{R}_z\mathbf{R}_y\dot{\mathbf{R}}_z\cdot(\mathbf{R}_z\mathbf{R}_y\mathbf{R}_z)^T=\mathbf{R}_z\mathbf{R}_y\dot{\mathbf{R}}_z\mathbf{R}_z^T\mathbf{R}_y^T\mathbf{R}_z^T=\mathbf{R}_z\mathbf{R}_y\,\mathbf{S}([0,0,\dot\phi_3]^T)\,\mathbf{R}_y^T\mathbf{R}_z^T=\mathbf{S}\!\left(\mathbf{R}_z\mathbf{R}_y[0,0,\dot\phi_3]^T\right)$。

第 4 步：合并三项，得到 $\boldsymbol\omega=\mathbf{B}\dot{\boldsymbol\phi}$。

由 $\mathbf{S}(\cdot)$ 的线性性，三项相加即

$$\boldsymbol\omega=[0,0,\dot\phi_1]^T+\mathbf{R}_z[0,\dot\phi_2,0]^T+\mathbf{R}_z\mathbf{R}_y[0,0,\dot\phi_3]^T$$

写成矩阵形式：

$$\boldsymbol\omega=\underbrace{\begin{bmatrix}0&-s_1&c_1 s_2\\0&c_1&s_1 s_2\\1&0&c_2\end{bmatrix}}_{\mathbf{B}}\begin{bmatrix}\dot\phi_1\\\dot\phi_2\\\dot\phi_3\end{bmatrix}$$

其中 $s_i=\sin\phi_i$，$c_i=\cos\phi_i$。这正是 eul2jac 返回的矩阵。

第 5 步：组装解析雅可比。

几何雅可比分块为 $\mathbf{J}=\begin{bmatrix}\mathbf{J}_v\\\mathbf{J}_\omega\end{bmatrix}$，其中 $\mathbf{J}_\omega$ 满足 $\boldsymbol\omega=\mathbf{J}_\omega\dot{\mathbf{q}}$。把 $\boldsymbol\omega=\mathbf{B}\dot{\boldsymbol\phi}$ 代入，得 $\dot{\boldsymbol\phi}=\mathbf{B}^{-1}\mathbf{J}_\omega\dot{\mathbf{q}}$，于是解析雅可比为

$$\mathbf{J}_a=\begin{bmatrix}\mathbf{J}_v\\ \mathbf{B}^{-1}\mathbf{J}_\omega\end{bmatrix}$$

当 $\mathbf{B}$ 非奇异时成立。$\mathbf{B}$ 的奇异条件为 $\det(\mathbf{B})=-s_2=0$，即 $\phi_2=0$ 或 $\pi$，对应 Euler 角的表示奇异（representational singularity），与机器人本身的几何奇异无关。

第 6 步（可选验证）。

用 Toolbox 验证：eul2jac(0.1,0.2,0.3) 应返回上述 $\mathbf{B}$ 在 $\phi=(0.1,0.2,0.3)$ 处的数值。原书未给出该具体数值，按符号推导即可；RPY 版 rpy2jac(0.1,0.2,0.3) 的数值为 $\begin{bmatrix}1&0&0.1987\\0&0.9950&-0.0978\\0&0.0998&0.9752\end{bmatrix}$，可作对照。

关键点

  • 解析雅可比 = 几何雅可比把角速度行换成姿态参数速率行：$\mathbf{J}_a=\begin{bmatrix}\mathbf{J}_v\\ \mathbf{B}^{-1}\mathbf{J}_\omega\end{bmatrix}$，$\mathbf{B}$ 由 eul2jac（Euler）或 rpy2jac（RPY）给出。
  • 推导核心是第 3 章 Eq. 3.4：$\dot{\mathbf{R}}\mathbf{R}^T=\mathbf{S}(\boldsymbol\omega)$，以及相似变换 $\mathbf{R}\mathbf{S}(\mathbf{x})\mathbf{R}^T=\mathbf{S}(\mathbf{R}\mathbf{x})$。
  • Euler 角 $\mathbf{B}$ 的奇异条件是 $\sin\phi_2=0$（$\phi_2=0,\pi$），这是表示奇异，不是机器人奇异；两者必须区分。
  • 解析雅可比只在 $\mathbf{B}$ 非奇异时可用；奇异处需改用几何雅可比或阻尼方法。

出处

  • 原书：Corke《Robotics, Vision and Control》 第 8 章
  • 依据：
  • 解析雅可比定义与 $\mathbf{J}_a=\begin{bmatrix}\mathbf{J}_v\\ \mathbf{B}^{-1}\mathbf{J}_\omega\end{bmatrix}$：本章事实底座 §3 概念 2、§4 推导链条第 6 步。
  • $\boldsymbol\omega=\mathbf{B}\dot{\boldsymbol\phi}$、eul2jac/rpy2jac：§1 记号约定、§3 概念 2。
  • $\dot{\mathbf{R}}\mathbf{R}^T=\mathbf{S}(\boldsymbol\omega)$（Eq. 3.4）与 $\mathrm{vex}(\cdot)$：§0 前后章依赖、§1 记号约定。
  • RPY 数值例 rpy2jac(0.1,0.2,0.3)：§6 例题与数值例子。
  • 表示奇异与几何奇异的区分：§3 概念 2。
题目 3. 可操作度（Manipulability，第 177 页）点击展开解答 ▾
预备：速度椭圆的数学来源

由本章 Eq. 8.2，瞬时正运动学为

$$\dot{\boldsymbol\xi}=\mathbf{J}(\mathbf{q})\,\dot{\mathbf{q}},\qquad \mathbf{J}\in\mathbb{R}^{6\times N}.$$

只关心末端 x、y 平移速度时，取 $\mathbf{J}$ 的前两行构成 $\mathbf{J}_{xy}\in\mathbb{R}^{2\times N}$，则 $\dot{\mathbf{p}}_{xy}=\mathbf{J}_{xy}\dot{\mathbf{q}}$。

第 1 步：为什么是椭圆。 设关节速度满足单位范数约束 $\|\dot{\mathbf{q}}\|=1$。所有可能的末端速度 $\dot{\mathbf{p}}_{xy}=\mathbf{J}_{xy}\dot{\mathbf{q}}$ 构成一个集合。由于 $\mathbf{J}_{xy}$ 是线性映射，单位球在 $\mathbb{R}^N$ 中的像是一个椭球（$N=2$ 时为椭圆），其半轴由 $\mathbf{J}_{xy}$ 的奇异值给出。这就是速度椭圆。

第 2 步：如何画。 令 $\dot{\mathbf{q}}=\cos\theta\,\mathbf{u}_1+\sin\theta\,\mathbf{u}_2$，其中 $\mathbf{u}_1,\mathbf{u}_2$ 为 $\mathbf{J}_{xy}$ 的右奇异向量（对应最大、最小奇异值），$\theta\in[0,2\pi)$。则

$$\dot{\mathbf{p}}_{xy}(\theta)=\sigma_1\cos\theta\,\mathbf{v}_1+\sigma_2\sin\theta\,\mathbf{v}_2,$$

其中 $\sigma_1,\sigma_2$ 为奇异值，$\mathbf{v}_1,\mathbf{v}_2$ 为左奇异向量。以当前末端位置 $\mathbf{p}$ 为中心，把 $\dot{\mathbf{p}}_{xy}(\theta)$ 画成曲线即得椭圆。

第 3 步：两连杆工作空间网格（a 小问）。 对工作空间内每个网格点，先用逆运动学求出对应的 $\mathbf{q}$（两连杆有解析解），再算 $\mathbf{J}_{xy}(\mathbf{q})$，按第 2 步画椭圆。原书未给出具体网格数值，按符号推导即可。

第 4 步：Puma 560 找更大可操作度的构型（b 小问）。 本章灵巧度定义为 Yoshikawa 度量

$$\omega=\sqrt{\det(\mathbf{J}\mathbf{J}^T)}.$$

事实底座给出：maniplty(qr,'yoshikawa')=0（ready pose 奇异，$\mathrm{rank}(\mathbf{J})=5$），maniplty(qn,'yoshikawa')=0.0786（名义位姿）。因此只需找一个非奇异、且 $\det(\mathbf{J}\mathbf{J}^T)$ 更大的构型即可，例如把 Puma 560 的肘部与腕部稍微偏离奇异位形。原书未给出该构型的具体关节角数值，按符号推导：搜索使 $\omega$ 最大的 $\mathbf{q}$，即最大化 $\det(\mathbf{J}\mathbf{J}^T)$。

第 5 步：叠加椭球与动画（c 小问）。 用 plot 显示机械臂后，在末端位置叠加由 $\mathbf{J}$ 的平移部分（前 3 行）或旋转部分（后 3 行）算出的椭球；沿轨迹逐帧更新 $\mathbf{q}$，重算 $\mathbf{J}$ 并重画椭球，即得动画。椭球在奇异附近会退化成一条线（某一半轴趋于 0），这正是可操作度下降的几何表现。

可运行代码（MATLAB，Robotics Toolbox）

% (a) 两连杆速度椭圆
L1 = 1; L2 = 1;
mdl = SerialLink([Revolute('d',0,'a',L1), Revolute('d',0,'a',L2)]);
for x = -1.5:0.5:1.5
  for y = -1.5:0.5:1.5
    q = mdl.ikine(transl(x,y,0), 'q0', [0 0]);   % 解析/数值逆解
    if isempty(q), continue; end
    J = mdl.jacob0(q); Jxy = J(1:2,:);
    [U,S,V] = svd(Jxy);
    th = linspace(0,2*pi,100);
    d = U*S*[cos(th); sin(th)];
    plot(x+d(1,:), y+d(2,:), 'b'); hold on
  end
end

% (b) Puma 560 搜索更大可操作度
mdl = mdl_puma560;
w_n = mdl.maniplty(qn, 'yoshikawa');   % = 0.0786
best = -inf; qbest = qn;
for k = 1:2000
  q = (rand(1,6)-0.5)*pi;
  w = mdl.maniplty(q, 'yoshikawa');
  if w > best, best = w; qbest = q; end
end
fprintf('w_n=%.4f, best=%.4f\n', w_n, best);

% (c) 沿轨迹动画叠加椭球
mdl.plot(qn); hold on
for t = 0:0.05:2
  q = qn + 0.3*sin(t)*[1 0 0 0 0 0];
  mdl.animate(q);
  J = mdl.jacob0(q); Jv = J(1:3,:);
  [U,S,~] = svd(Jv);
  plot_ellipsoid(mdl.fkine(q).t, U*S);   % 自定义椭球绘制
  drawnow
end

预期观察：两连杆在工作空间中心附近椭圆接近圆形，靠近边界时退化成扁椭圆；Puma 560 在 $q_r$ 处 $\omega=0$（退化），在 $q_n$ 处 $\omega=0.0786$，随机搜索可找到更大的 $\omega$；动画中椭球在奇异附近明显变扁。

关键点

  • 速度椭圆 = 单位关节速度球经 $\mathbf{J}$ 的像，半轴长度等于 $\mathbf{J}$ 的奇异值，方向等于左奇异向量；椭圆退化即奇异。
  • Yoshikawa 灵巧度 $\omega=\sqrt{\det(\mathbf{J}\mathbf{J}^T)}$ 正比于速度椭球体积；$\omega=0$ 当且仅当 $\mathbf{J}$ 降秩（奇异）。
  • 事实底座给出的锚点：maniplty(qr,'yoshikawa')=0、maniplty(qn,'yoshikawa')=0.0786，$q_r$ 处 $\mathrm{rank}(\mathbf{J})=5$。
  • 平移椭圆用 $\mathbf{J}$ 前 3 行，旋转椭圆用后 3 行；两者形状不同，不要混用。
  • 动画的本质是沿轨迹逐帧重算 $\mathbf{J}(\mathbf{q})$ 并重画椭球，用于直观展示可操作度随构型变化。

出处

  • 原书：Corke《Robotics, Vision and Control》第 8 章 Velocity Relationships
  • 依据：
  • 速度椭圆与可操作度定义：本章 facts 第 3 节第 5 条、第 5 节第 6 条（Yoshikawa $\omega=\sqrt{\det(\mathbf{J}\mathbf{J}^T)}$）
  • 瞬时正运动学 $\dot{\boldsymbol\xi}=\mathbf{J}\dot{\mathbf{q}}$：facts 第 5 节第 1 条（Eq. 8.2）
  • maniplty(qr,'yoshikawa')=0、maniplty(qn,'yoshikawa')=0.0786、$q_r$ 处 $\mathrm{rank}(\mathbf{J})=5$：facts 第 6 节例题数值
  • 奇异与条件数：facts 第 3 节第 4、5 条

解答

本题是围绕本章 resolved-rate motion control（第 8.3 节，Eq. 8.6–8.8）的一组动手实验，核心是 $\dot{\mathbf{q}}=\mathbf{J}^{-1}(\mathbf{q})\boldsymbol\nu^*$ 及其各种"求逆"替代方案。下面逐小问分析。

a) 不同速度指令与组合。

由 Eq. 8.2，$\dot{\boldsymbol\xi}=\mathbf{J}(\mathbf{q})\dot{\mathbf{q}}$，其中 $\boldsymbol\nu=(v_x,v_y,v_z,\omega_x,\omega_y,\omega_z)$。给定 $\boldsymbol\nu^*$，用 Eq. 8.6 求 $\dot{\mathbf{q}}=\mathbf{J}^{-1}\boldsymbol\nu^*$。分别令 $\boldsymbol\nu^*$ 只含平移分量、只含旋转分量、以及两者组合，观察关节速度 $\dot{\mathbf{q}}$ 的分配。预期：纯平移主要激励前三个关节，纯旋转主要激励腕部关节；组合时各关节速度线性叠加（因为 $\mathbf{J}$ 是线性映射）。原书未给出具体数值，按符号推导。

b) 记录 $\det(\mathbf{J})$。

在 Simulink 中把 jacob0(q) 的输出接入 det 模块，再接到 To Workspace。预期：当机器人接近奇异位形时 $\det(\mathbf{J})\to 0$。本章事实底座给出近奇异例 $\det(\mathbf{J})=-1.5509\times10^{-5}$、$\mathrm{cond}(\mathbf{J})=235.2498$，可作为参照量级。

c) 仿真延长到 10 s。

图 8.4 是开环 resolved-rate 积分（Eq. 8.7）：

$$\mathbf{q}^*_{\langle k+1\rangle}=\mathbf{q}^*_{\langle k\rangle}+\mathbf{J}^{-1}(\mathbf{q}^*_{\langle k\rangle})\,\boldsymbol\nu^*\,\delta t.$$

开环积分会累积数值漂移误差，末端位姿逐渐偏离期望轨迹。延长到 10 s 后，误差进一步累积，末端可能明显偏离目标路径。这正是本章强调要用闭环 resolved-rate（Eq. 8.8）的原因：

$$\dot{\mathbf{q}}^*=\mathbf{J}^{-1}(\mathbf{q})\,\mathbf{K}_p\,\Delta(\boldsymbol\xi^*_{\langle k\rangle},\boldsymbol\xi_{\langle k\rangle}),$$

其中 $\Delta(\cdot)$ 是位姿差 6-vector（Eq. 3.10，tr2delta），$\mathbf{K}_p$ 为比例增益，可消除漂移。

d) 模仿第 7.4.3 节，到达奇异。

第 7.4.3 节讨论的是解析逆解在奇异附近的问题。当机器人到达奇异位形时 $\det(\mathbf{J})=0$，$\mathbf{J}$ 列线性相关，$\mathbf{J}^{-1}$ 不存在。此时 Eq. 8.6 无解或关节速度爆炸。本章事实底座给出 Puma ready pose $\mathbf{q}_r$ 的 $\mathrm{rank}(\mathbf{J})=5$，jsingu(J) 输出 "1 linearly dependent joints: q6 depends on: q4"，即丢失一个自由度。近奇异例中要求 $\boldsymbol\nu=[0,0,0.1,0,0,0]^T$ 得 $\dot{\mathbf{q}}=[-0.0000,\ -4.9261,\ 9.8522,\ 0,\ -4.9261,\ 0]$，关节速度已达数 rad/s，而同样位形下绕 $y$ 轴 0.2 rad/s 只需 $\dot{\mathbf{q}}=[0,0,0,0,-0.2,0]$。这说明奇异附近关节速度对笛卡尔速度极度敏感。

e) 用 pinv 替换 Jacobian inverse。

pinv 计算 Moore–Penrose 伪逆。对 $N>6$ 的冗余机器人，左伪逆为 Eq. 8.9：

$$\mathbf{J}^+=\mathbf{J}^T(\mathbf{J}\mathbf{J}^T)^{-1},$$

给出最小范数解 $\dot{\mathbf{q}}=\mathbf{J}^+\boldsymbol\nu^*$。对 $N=6$ 方阵，pinv 在非奇异时等于 $\mathbf{J}^{-1}$，在奇异附近给出最小范数解而非无穷大。预期：奇异附近关节速度不再爆炸，但末端无法精确跟踪指令。

f) 阻尼最小二乘。

用阻尼逆

$$\mathbf{J}^T(\mathbf{J}\mathbf{J}^T+\mu^2\mathbf{I})^{-1}$$

替换。$\mu$ 为阻尼因子：$\mu\to 0$ 退化为伪逆，$\mu$ 增大则奇异附近关节速度被抑制，但末端跟踪精度下降。预期：存在 $\mu$ 的折中值，使奇异附近既不过冲又保持可接受的跟踪误差。原书未给出具体 $\mu$ 数值，按符号推导。

g) 用 lscov。

lscov 求解加权最小二乘 $\min\|\mathbf{J}\dot{\mathbf{q}}-\boldsymbol\nu^*\|$。它等价于伪逆解，但可引入权重矩阵。预期：结果与 pinv 类似，但可通过权重调节各关节的"代价"。

h) 8 轴机器人（第 7.3.4 节）。

8 轴机器人 $N=8>6$，是冗余的。用 Eq. 8.9 的伪逆求最小范数解。预期：末端执行器轨迹重复（因为任务是 6 维的），但关节坐标轨迹不重复——因为零空间分量可以自由变化，每次积分可能落到不同的关节构型。这正是冗余自由度的特征。

i) 加入零空间运动。

用 Eq. 8.10：

$$\dot{\mathbf{q}}=\mathbf{J}^+\boldsymbol\nu^*+\mathbf{N}\mathbf{N}^+\dot{\mathbf{q}}_{ns},$$

其中 $\mathbf{N}=\mathrm{null}(\mathbf{J})$ 是零空间基，$\mathbf{N}\mathbf{N}^+$ 把额外任务 $\dot{\mathbf{q}}_{ns}$ 投影进零空间，不干扰末端运动。设计 $\dot{\mathbf{q}}_{ns}$ 使关节远离限位（例如朝关节范围中心方向）。预期：末端轨迹不变，但关节轨迹被"推"向安全区域。

关键点

  • resolved-rate 的本质：用 $\dot{\mathbf{q}}=\mathbf{J}^{-1}\boldsymbol\nu^*$（Eq. 8.6）把笛卡尔速度指令翻译成关节速度，绕开逆运动学。
  • 开环 vs 闭环：开环积分（Eq. 8.7）会漂移；闭环（Eq. 8.8）用 $\Delta(\cdot)$ 位姿差 + $\mathbf{K}_p$ 消除漂移。
  • 奇异处理：$\det(\mathbf{J})=0$ 时 $\mathbf{J}^{-1}$ 失效，改用伪逆（Eq. 8.9）、阻尼逆或 pinv/lscov。
  • 冗余与零空间：$N>6$ 时用 $\mathbf{J}^+$ 得最小范数解，用 $\mathbf{N}\mathbf{N}^+$（Eq. 8.10）把额外任务投影进零空间，实现关节限位回避而不影响末端。
  • 灵巧度：$\omega=\sqrt{\det(\mathbf{J}\mathbf{J}^T)}$（Yoshikawa），maniplty(qr,'yoshikawa')=0 表示奇异，maniplty(qn,'yoshikawa')=0.0786 表示非奇异。

背景与建模

P8 是一个过驱动系统：Puma 560（6 关节）安装在一个 2 自由度定位基座上，共 $N=8$ 个关节。记广义坐标 $\mathbf{q}\in\mathbb{R}^8$，其中 $\mathbf{q}_b=(q_1,q_2)$ 为基座关节，$\mathbf{q}_a=(q_3,\dots,q_8)$ 为 Puma 的 6 个关节。末端空间速度满足本章 Eq. 8.2：

$$\dot{\boldsymbol\xi}=\mathbf{J}(\mathbf{q})\,\dot{\mathbf{q}},\qquad \mathbf{J}\in\mathbb{R}^{6\times 8}$$

由于 $N=8>6$，$\mathbf{J}$ 是"宽"矩阵，存在冗余。按本章事实底座第 7 条，冗余时用左伪逆得最小范数解，并用零空间投影实现附加任务（Eq. 8.9/8.10）：

$$\dot{\mathbf{q}}=\mathbf{J}^+\boldsymbol\nu^*+\mathbf{N}\mathbf{N}^+\dot{\mathbf{q}}_{ns},\qquad \mathbf{J}^+=\mathbf{J}^T(\mathbf{J}\mathbf{J}^T)^{-1}$$

其中 $\mathbf{N}=\mathrm{null}(\mathbf{J})$，$\mathbf{N}\mathbf{N}^+$ 把附加任务投影到零空间，不干扰末端运动。

a) 零空间控制器

目标 1：让后六个关节停在行程中点。

设 $\mathbf{q}_a$ 的期望中点为 $\mathbf{q}_{a,\text{mid}}$（由关节限位决定，原书未给出具体数值，按符号推导）。定义次级任务速度：

$$\dot{\mathbf{q}}_{ns,1}=\mathbf{K}_a\,(\mathbf{q}_{a,\text{mid}}-\mathbf{q}_a)$$

其中 $\mathbf{K}_a$ 为正定增益矩阵。代入 Eq. 8.10：

$$\dot{\mathbf{q}}=\mathbf{J}^+\boldsymbol\nu^*+\mathbf{N}\mathbf{N}^+\,\dot{\mathbf{q}}_{ns,1}$$

为什么可行：$\mathbf{N}\mathbf{N}^+$ 把 $\dot{\mathbf{q}}_{ns,1}$ 投影到 $\mathbf{J}$ 的零空间，因此该分量不产生任何末端速度，末端仍精确跟踪 $\boldsymbol\nu^*$；同时基座两关节 $q_1,q_2$ 被"借用"来补偿，使 $\mathbf{q}_a$ 回归中点。

目标 2：最大化可操作度。

按本章事实底座第 5 条与第 6 条，Yoshikawa 灵巧度

$$\omega=\sqrt{\det(\mathbf{J}\mathbf{J}^T)}$$

最大化 $\omega$ 等价于沿 $\omega$ 的梯度方向运动。取次级任务

$$\dot{\mathbf{q}}_{ns,2}=k_\omega\,\nabla_{\mathbf{q}}\,\omega(\mathbf{q})$$

（梯度可用数值差分或解析式求得；原书未给出 P8 的具体梯度表达式，按符号推导）。同样投影进零空间：

$$\dot{\mathbf{q}}=\mathbf{J}^+\boldsymbol\nu^*+\mathbf{N}\mathbf{N}^+\,\dot{\mathbf{q}}_{ns,2}$$

为什么可行：$\omega$ 只依赖构型 $\mathbf{q}$，沿其梯度在零空间内移动可改善灵巧度而不改变末端速度。注意当 $\omega\to 0$（接近奇异）时梯度可能病态，需加阻尼或限幅。

非完整移动基座扩展（挑战性）。

此时基座不再是 2 个转动关节，而是独轮车模型（属第 4–6 章，本章不展开其运动学）。思路：把移动基座的位姿 $(x,y,\theta)$ 视为额外广义坐标，其速度受非完整约束（不能侧滑）。控制器分两层：

  1. 上层用本章 resolved-rate 思想（Eq. 8.6/8.8）计算期望的基座位姿速度，使 Puma 处于有利构型；
  2. 下层用非完整控制律（如输入-输出线性化或 Lyapunov 方法）把该位姿速度转换为转向角速度与前进线速度。

由于非完整约束使基座速度不能任意指定，零空间投影需替换为受约束的投影，这正是本题"挑战性"所在。

b) 锁定哪两个关节的算法

对任意位姿 $\mathbf{q}$ 和末端空间速度 $\boldsymbol\nu^*$，要从 8 个关节中锁定 2 个、驱动 6 个。锁定关节意味着对应列从 $\mathbf{J}$ 中删除，得到 $6\times 6$ 方阵 $\mathbf{J}_{\text{red}}$，要求其非奇异（可逆）。

算法（穷举 + 条件数判据）：

输入: q, ν*
输出: 应锁定的两个关节索引 (i*, j*)

best = ∞
for each 组合 (i, j), 1 ≤ i < j ≤ 8:
    J_red = J(q) 删除第 i, j 列      # 6×6
    if |det(J_red)| < ε:             # 奇异，跳过
        continue
    c = cond(J_red)                  # 条件数
    if c < best:
        best = c
        (i*, j*) = (i, j)
return (i*, j*)

为什么这样选：删除列后 $\mathbf{J}_{\text{red}}$ 必须可逆才能解 $\dot{\mathbf{q}}_{\text{red}}=\mathbf{J}_{\text{red}}^{-1}\boldsymbol\nu^*$（Eq. 8.6）。条件数 $\mathrm{cond}(\mathbf{J}_{\text{red}})$ 越小，越远离奇异，关节速度越不易爆炸（对应本章事实底座第 4、5 条）。共 $\binom{8}{2}=28$ 种组合，计算量可接受。

可运行验证代码（Python，示意）：

import numpy as np
from itertools import combinations

def choose_locked_joints(J, eps=1e-9):
    n = J.shape[1]
    best_cond, best_pair = np.inf, None
    for i, j in combinations(range(n), 2):
        cols = [c for c in range(n) if c not in (i, j)]
        J_red = J[:, cols]
        if abs(np.linalg.det(J_red)) < eps:
            continue
        c = np.linalg.cond(J_red)
        if c < best_cond:
            best_cond, best_pair = c, (i, j)
    return best_pair, best_cond

预期观察：在 Puma ready pose $\mathbf{q}_r$ 附近，$\mathrm{rank}(\mathbf{J})=5$（见事实底座第 6 节），说明此时 $\mathbf{J}$ 本身已降秩，任何 $6\times 6$ 子阵都可能奇异，算法会返回 None 或提示无可行锁定组合——这正说明该位姿不适合锁定两关节。

关键点

  • 零空间投影 $\mathbf{N}\mathbf{N}^+$ 是冗余机器人做次级任务的核心工具：附加任务不干扰末端速度（Eq. 8.10）。
  • 可操作度 $\omega=\sqrt{\det(\mathbf{J}\mathbf{J}^T)}$ 是构型好坏的标量度量，其梯度可作为零空间次级任务。
  • 锁定关节 = 删列：删列后必须保证 $6\times 6$ 子阵非奇异，用条件数选最优组合。
  • 过驱动 vs 欠驱动：$N>6$ 用左伪逆 $\mathbf{J}^+=\mathbf{J}^T(\mathbf{J}\mathbf{J}^T)^{-1}$；$N<6$ 需删行（partition）。
  • 非完整基座使零空间投影不再直接适用，需叠加非完整约束控制律。
