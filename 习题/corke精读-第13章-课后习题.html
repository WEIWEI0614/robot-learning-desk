题目 1. 灰度分类点击展开解答 ▾

本题是动手实验题，原书未给出唯一数值答案，以下给出可运行代码与预期观察，数值凡未在事实底座中出现的均标注「原书未给出具体数值」。

a) ithresh 试验

ithresh 是交互式阈值工具，允许拖动滑块观察二值化结果。对 castle_sign.png：

castle = iread('castle_sign.jpg', 'grey', 'double');
idisp(castle)
t = ithresh(castle);   % 交互式拖动，观察 c = (I >= t)

预期观察：直方图呈双峰——小峰约 $0.9$（亮像素，即字符），宽高峰约 $0.3$（暗背景/砖）。事实底座给出 idisp(castle >= 0.6) 时 $t=0.6$ 可行，$t=0.7$ 也可行；otsu(castle) 返回 $0.6000$。对 castle_sign2.png，原书未给出具体数值，但加入对角梯度后 Otsu 阈值变为 $0.5412$，分类效果变差——说明全局阈值对光照/梯度敏感，这正是引入自适应阈值（Niblack、MSER）的动机。

b) Niblack 算法

Niblack 用局部均值 $\mu$ 与标准差 $\sigma$ 计算逐像素阈值：

t = niblack(castle, -0.2, 35);   % k = -0.2, 窗口半宽 = 35
idisp(castle >= t)

事实底座：字符高约 50–70 像素，窗口半宽取 35（即窗口约 71 像素，覆盖字符高度量级），$k=-0.2$，结果出现大量 false positives。

参数影响（按符号推导，原书未给出具体数值）：

  • $k$ 越负 → 阈值越低 → 更多像素被判为前景 → false positives 增多；$k$ 越正 → 前景收缩。
  • 窗口太小 → 局部统计噪声大，区域内部出现空洞；窗口太大 → 退化为全局阈值，失去自适应能力。经验上窗口应略大于目标笔画宽度。

c) 对 MSER 输出应用 iblobs，按包围盒尺寸筛字母

[mser, nsets] = imser(castle, 'light');   % nsets = 40
% 对每个 MSER 集合做连通域标记与 blob 描述
for i = 1:nsets
    f = iblobs(mser(:,:,i));
    % 字母筛选：包围盒宽高在合理范围内，且宽高比接近字符
    for j = 1:length(f)
        w = f(j).umax - f(j).umin;
        h = f(j).vmax - f(j).vmin;
        if w > 10 && w < 60 && h > 30 && h < 90
            % 候选字母 blob
        end
    end
end

事实底座给出字符高约 50–70 像素，故高度阈值取 $[30,90]$ 可覆盖；宽度按字符宽高比（约 $0.5$–$0.8$）取 $[10,60]$。iblobs 返回的 RegionFeature 含 umin,umax,vmin,vmax（包围盒）、area、cent、theta、b/a 等字段，可直接用于筛选。原书未给出该筛选的具体数值结果。

d) imser 参数探索

  • 'Delta'：阈值步长，控制 MSER 检测的阈值采样密度。越小 → 检测越细但越慢。
  • 'MinDiversity'：区域多样性下限，抑制嵌套的重复区域。增大 → 保留更少、更独立的区域。
  • 'MaxVariation'：允许的区域变化上限，控制稳定性判据。增大 → 接受更多不稳定区域。
  • 'MinArea' / 'MaxArea'：区域面积上下限，直接过滤过大/过小区域。

预期：调大 MinArea 可去掉噪声小区域；调小 MaxVariation 只保留最稳定区域；MinDiversity 增大可减少同一字符的重复检测。原书未给出各参数的具体数值。

e) igraphcut 应用于 castle_sign2.png

im2 = iread('castle_sign2.png', 'grey', 'double');
[cls, ...] = igraphcut(im2, 1500, 100, 0.5);

事实底座给出 igraphseg(im, 1500, 100, 0.5) 的参数含义：$k=1500$（相似度尺度）、最小分量 100 像素、Gaussian $\sigma=0.5$，得到 $m=28$ 个区域。igraphcut 同属图割分割族，参数调整方向：

  • $k$ 增大 → 允许更大灰度差仍归为同区域 → 区域变大、数量减少。
  • 最小分量增大 → 小区域被合并 → 抑制碎片。
  • $\sigma$ 增大 → 平滑增强 → 边界更平滑但细节丢失。

预期：调参后 castle_sign2.png 中字符与背景应被分到不同类，从而改善二值化质量。原书未给出该图的具体分割数值。

关键点

  • 全局阈值脆弱：otsu(castle)=0.6000 在干净图上可行，但 castle_sign2.png 加梯度后降到 $0.5412$ 且效果差——光照/梯度变化是引入 Niblack、MSER、图割的根本原因。
  • Niblack 参数耦合：$k$ 控制阈值偏移方向，窗口大小需匹配目标笔画尺度（字符高 50–70 像素 → 半宽约 35）；$k=-0.2$ 时 false positives 多。
  • MSER 输出是区域集合：imser 返回 nsets=40 个集合，需逐集合 iblobs 后用包围盒 umin/umax/vmin/vmax 按字母尺寸筛选。
  • imser 五参数各司其职：Delta 控采样密度，MinDiversity 去嵌套，MaxVariation 控稳定性，MinArea/MaxArea 控尺寸。
  • 图割参数语义：$k$ 控相似度尺度、最小分量控碎片、$\sigma$ 控平滑，三者共同决定分割粒度。

  • iblobs 与 RegionFeature 字段（umin/umax/vmin/vmax、area、cent、theta、b/a）：事实底座第 1 节记号约定、第 4 节推导链条第 5 步、第 6 节例题

题目 2. 颜色分类点击展开解答 ▾

a) 改变簇数 $k$，是否存在最佳值？

colorkmeans(im, C) 把像素映射到 xy-chromaticity 平面后聚成 $C$ 簇，训练阶段求簇心 cxy，分类阶段廉价分配。原书 targets 示例用 $C=4$：

cxy = [0.3331 0.2862 0.4049 0.2947;
       0.3544 0.3088 0.4414 0.3215]
resid = 6.2583

其中第 3 簇 colorname(cxy(:,3),'xy') = 'banana'（黄色目标）。garden 示例同样用 $C=4$，番茄对应 $c=2$。

做什么 + 为什么：$k$ 是 k-means 的先验簇数，没有解析最优解。判断标准是"分类后目标是否被单独分到一个簇、且该簇不被背景污染"。$k$ 太小 → 目标与背景颜色合并；$k$ 太大 → 目标被拆成多簇、且随机初始化方差增大。原书未给出 $k$ 的"最佳值"数值，按符号推导：应取使 resid 下降趋于平缓、且目标簇在 colorname 下语义明确的最小 $k$。对 targets 图，$k=4$ 已能把 banana 单独分出，故 $k=4$ 是可用值而非唯一最优。

b) 随机初始化的差异

kmeans(a,3) 在 a = rand(2,500) 上给出 r = 4.3166（残差）。'random'/'spread' 选项随机选初始簇心，k-means 只保证收敛到局部极小。

做什么 + 为什么：多次运行并比较 cxy 与 resid。若各次 resid 接近、簇心排列相近，则解稳定；若差异大，说明目标簇可能在某次运行中与背景合并。原书未给出多次运行的数值，按符号推导：应报告 resid 的极差与簇心的最大偏移，并据此决定是否固定随机种子或改用 'spread' 初始化。

c) 判定哪个簇是目标

思路：目标颜色已知（黄或红），在 xy-chromaticity 平面上与簇心比较。

function k = findtarget(cxy, target)
% cxy: 2xC 簇心（第1行 x，第2行 y）
% target: 'yellow' 或 'red'
  switch target
    case 'yellow'
      ref = [0.4049; 0.4414];   % 原书 banana 簇心
    case 'red'
      ref = [0.5388; 0.3335];   % 原书 garden 番茄簇心
  end
  d = sqrt(sum((cxy - ref).^2, 1));
  [~, k] = min(d);
end

做什么 + 为什么：颜色是强分割线索，但簇的编号由 k-means 任意分配，不能硬编码 cls==3。用 colorname(cxy(:,i),'xy') 也可直接读出语义名（原书对第 3 簇返回 'banana'）。两种方式等价，前者更通用。

d) igraphcut 的表现与调参

原书 igraphseg(im, 1500, 100, 0.5) 给出 m = 28，其中 $k=1500$ 为分割参数、最小分量 100 像素、Gaussian $\sigma=0.5$。

做什么 + 为什么：igraphcut 基于图割，把像素相似性与空间邻近性联合优化，比纯阈值/颜色聚类更能保住目标边界。调参方向：增大最小分量阈值 → 去掉小碎块；调整 $k$ → 控制区域合并强度；$\sigma$ 控制平滑。原书未给出 igraphcut 在 targets/garden 上的具体数值，按符号推导：应以"目标区域是否完整、是否与背景分离"为判据，逐步增大最小分量直到碎块消失而目标不裂。

e) 形态学清理参数

原书两例：

  • targets：iopen(cls3, kcircle(2)) —— 开运算去小噪点；
  • garden：iclose(cls2, kcircle(15)) —— 闭运算填补番茄内部空洞。

做什么 + 为什么：开运算（先腐蚀后膨胀）删除小于结构元的亮区；闭运算（先膨胀后腐蚀）填补小于结构元的暗洞。结构元半径是关键：太小 → 清理不净；太大 → 目标被侵蚀或与邻目标粘连。原书未给出半径扫描的数值，按符号推导：应从 1 递增，观察 iblobs 返回的 area 与 touch 标志何时稳定。

f) 摄像头循环分类

cam = webcam;                       % 或 VideoCamera
% 预学习颜色簇（离线）
% [cls, cxy, resid] = colorkmeans(im_train, 4);
while true
    im = snapshot(cam);
    im = im2double(rgb2gray(im));   % 灰度阈值方案
    t  = otsu(im);
    c  = (im >= t);
    idisp(c);
    % 颜色方案：cls = colorkmeans(im, 4); idisp(cls == k);
end

做什么 + 为什么：把离线学到的 cxy 固定，在线只做"分配最近簇心"这一步，因此每帧开销极低。灰度阈值方案用 otsu 自适应光照；颜色方案对光照变化更鲁棒但需要预先采集训练图。原书未给出摄像头帧率等数值，按符号推导：应保证每帧分类 + 显示在实时预算内。

关键点

  • k-means 的簇数 $k$ 与随机初始化都是先验/随机因素，没有解析最优；判据是目标簇的语义可分性与 resid 的稳定性。
  • 簇编号是任意的，必须用颜色参考或 colorname 判定目标簇，不能硬编码索引。
  • 形态学清理的结构元半径直接决定 area/touch，是分割流水线中最敏感的参数之一。
  • 在线分类应复用离线学到的 cxy，只做最近簇心分配，保证实时性。
  • 本章所有分割/描述结果最终服务于第 14 章的 correspondence 与 3D 恢复。

出处

  • 原书：Corke《Robotics, Vision and Control》第 13 章 Image Feature Extraction
  • 依据：
  • 颜色聚类与 colorkmeans、cxy/resid 数值：事实底座第 3 节第 3 条、第 4 节第 2 步、第 6 节 targets/garden 示例
  • kmeans(a,3) → r = 4.3166：事实底座第 6 节
  • colorname(cxy(:,3),'xy') = 'banana'：事实底座第 6 节
  • iopen(cls3, kcircle(2))、iclose(cls2, kcircle(15))：事实底座第 4 节第 3 步、第 6 节
  • igraphseg(im, 1500, 100, 0.5) → m = 28：事实底座第 6 节
  • 阈值化 otsu/niblack/mser：事实底座第 3 节第 2 条、第 4 节第 2 步

题目 3. Blobs（区域/blob 特征）。点击展开解答 ▾

本题是动手实验题，下面按小题给出思路、公式与可运行代码（MATLAB + 工具箱风格，遵循本章记号）。

a) 外边界、内边界与总边界。

用 ilabel 得到连通域标签与拓扑（parents/cls），再用 iblobs(...,'boundary') 提取边界。外边界是 blob 与背景相接的轮廓；内边界是孔洞轮廓（孔洞在拓扑上是该 blob 的 children）；总边界 = 外边界 + 所有内边界。本章事实底座给出：f(1).edge 为 2×154 的边界点序列，前五点 (142,116)(142,117)(141,118)(140,119)(139,120)，说明边界以像素坐标序列存储。

im = iread('myholes.png','grey','double');
binary = im >= 0.5;                 % 阈值化，c=1 当 I>=t
[label, m, parents, cls] = ilabel(binary);
f = iblobs(binary, 'boundary', 'class', 1);
% 外边界：f(k).edge；内边界：f(k).children 对应的边界
for k = 1:length(f)
    fprintf('blob %d: area=%d, parent=%d, children=%s\n', ...
        k, f(k).area, f(k).parent, mat2str(f(k).children));
end

b) 拓扑层次显示。

ilabel 返回 parents 与 cls，iblobs 的 parent/children 字段给出层次。事实底座示例：parents' = [0 0 2 3 2]，cls' = [1 0 1 0 1]，说明 label 4 是背景（class 0），其 children 为 [1 2 3 5]。把孔洞中的小物体作为子 blob 显示即可。

f = iblobs(binary, 'class', 1);
for k = 1:length(f)
    fprintf('blob %d children: %s\n', k, mat2str(f(k).children));
end

c) circularity 随尺度的变化。

本章 circularity 由周长与面积定义（事实底座：perim、circ，如 circ=0.417/0.421、circ=0.641/0.958）。对同一形状缩放，理想连续情况下 circularity 不变；但离散像素化使小尺度下周长被高估（阶梯效应），circularity 下降。曲线形状：大尺度趋于常数，小尺度明显偏低。

scales = 10:10:200;
circ = zeros(size(scales));
for i = 1:length(scales)
    im = makeshape(scales(i));       % 生成该尺度下的形状
    f = iblobs(im >= 0.5, 'boundary', 'class', 1);
    circ(i) = f(1).circ;
end
plot(scales, circ, '-o'); xlabel('scale'); ylabel('circularity');

d) 正方形周长：估计 vs 真实。

真实周长 $P_{\text{true}} = 4s$。估计周长由链码给出（事实底座：4 方向链码 14、Freeman 8 方向 12.2、crack code 18 像素）。小正方形时，像素化使估计周长相对误差增大，曲线偏离直线。

s = 2:2:100;
Ptrue = 4*s;
Pest = zeros(size(s));
for i = 1:length(s)
    im = zeros(120,120); im(10:10+s(i)-1,10:10+s(i)-1) = 1;
    f = iblobs(im, 'boundary', 'class', 1);
    Pest(i) = f(1).perim;
end
plot(s, Ptrue, 'k-', s, Pest, 'r--'); legend('true','estimated');

e) 形状分类器。

用 aspect ratio $b/a$ 与 circularity 作为二维特征，对若干形状（圆、方、椭圆）做最近邻或阈值分类。事实底座给出 b/a=0.6746、shape=0.6746、circ=0.417/0.421 等数值，可作为特征量级参考。再用 Hu 矩（事实底座：humoments(L==2) → 0.4181 0.0292 0.0230 0.0017 0.0000 0.0003 0.0000）重复。Hu 矩对尺度/旋转更稳健，通常分类性能更好。

f = iblobs(binary, 'class', 1);
X = [[f.shape]; [f.circ]]';        % b/a 与 circularity
% 简单最近邻分类

f) 边界匹配与角度图。

用 boundary() 得极坐标签名 $(r,\theta)$，boundmatch(r1,r2) 找相对旋转。事实底座：P2.png 中相对朝向 45.1267 度。修改代码绘制边缘段角度 $k$ 对 $\theta$ 的图。

[r1,theta1] = boundary(f(1).edge);
[r2,theta2] = boundary(f(2).edge);
[th, s] = boundmatch(r1, r2);
plot(theta1, r1, theta2, r2);      % 签名对比

g) 对齐矩形。

等效椭圆由惯性矩阵 $\mathbf{J}$ 的特征向量给出主轴方向（事实底座：特征向量 x = [-0.9954 -0.0962; -0.0962 0.9954]，主轴角 95.5498 度）。对齐矩形边平行于这两个主轴，且完全包含 blob。计算步骤：把 blob 像素旋转到主轴坐标系，取 $u,v$ 的 min/max 得矩形，再旋转回原坐标系。两个特征：矩形 aspect ratio、blob 面积 / 矩形面积。

f = iblobs(binary, 'class', 1);
blob = f(1);

% aspect = width/height; fill = blob.area / (width*height);

关键点

  • 拓扑层次：ilabel 的 parents/cls 与 iblobs 的 parent/children 是描述孔洞结构的关键；背景 class 0 常是根节点。
  • 离散化效应：circularity 与周长在小尺度下因像素阶梯而失真，这是曲线形状的根源。
  • 不变特征：aspect ratio $b/a$、circularity、Hu 矩、对齐矩形的两个比值都是尺度/旋转不变特征，适合做形状分类。
  • 等效椭圆与惯性矩阵：$\mathbf{J}$ 的特征值给 $a,b$，特征向量给主轴角，是对齐矩形与形状描述的基础。
  • 边界匹配：极坐标签名 $(r,\theta)$ 加 boundmatch 可估计相对旋转，是第 14 章 correspondence 的雏形。

题目 4. Hough 变换点击展开解答 ▾

本题是动手实验题，围绕本章第 5 条核心概念「Hough 变换」展开。Hough 变换把边缘点映射到 $(\rho,\theta)$ 参数空间，用累加器 $\mathbf{A}\in\mathbb{Z}^{N_\theta\times N_\rho}$ 投票找峰，每个峰对应一条直线。下面逐小问给出做法与预期观察。

a) 改变累加器大小

累加器默认 $401\times400$ bins（$\theta$ 方向 401，$\rho$ 方向 400）。在 MATLAB 工具箱中可通过 Hough(edges, 'houghThresh', ...) 及内部 bin 数控制。做法：固定同一幅边缘图，分别用粗、细量化运行，比较 h.lines() 返回的直线条数与 strength。

  • 量化过粗（bin 少）：多条邻近直线落入同一 bin，峰被合并，检测到的直线数偏少，$\rho,\theta$ 分辨率低。
  • 量化过细（bin 多）：投票分散，单条直线可能分裂成多个相邻峰，出现重复直线；此时需要更大的 'suppress' 来合并。

预期：直线条数随 bin 数先增后趋于稳定，$\theta$ 分辨率提高时角度估计更精细。原书未给出具体 bin 数与对应直线数的数值，按符号推导。

b) 用 Sobel 代替 Canny

Canny 给出细化的二值边缘；Sobel 给出梯度幅值图（本章依赖第 12 章结论：Sobel/Canny 梯度、derivative of Gaussian）。做法：edges_sobel = ...（对 Sobel 幅值取阈值二值化），再送入 Hough。

预期：Sobel 边缘更粗、含更多弱响应点，投票更分散，累加器峰更宽、伪峰更多；需配合更高 'EdgeThresh' 或更大 'suppress'。Canny 因非极大值抑制与滞后阈值，边缘更干净，峰更尖锐。原书未给出两者直线数的具体数值。

c) 调参

  • 'suppress'：非局部极大值抑制的邻域半径。本章事实底座给出示例 'suppress', 5 用于抑制量化伪峰。增大它 → 合并邻近峰，直线数减少；减小 → 保留更多峰。
  • 'interpSize'：峰值插值窗口，用于把离散 bin 峰细化到亚 bin 精度，改善 $\rho,\theta$ 估计。
  • 'EdgeThresh'：边缘二值化阈值，控制进入投票的边缘点数量。
  • 'houghThresh'：累加器峰值接受阈值，直接决定哪些峰被报告为直线。

预期：'houghThresh' 与 'suppress' 对直线条数影响最直接；'interpSize' 主要影响参数精度而非条数。原书未给出各参数的具体取值-结果对照表。

d) 应用到自己的图像

im = iread('myimage.jpg', 'grey', 'double');
edges = icanny(im);              % 或 isobel
h = Hough(edges);
h.show();                        % 查看累加器
lines = h.lines();               % 含 theta、rho、strength

预期：人造环境（建筑、标牌）中直线普遍，累加器出现明显亮峰；自然场景峰较弥散。可用 seglength 筛 length > 100 保留长直线。

e) 摄像头循环 + 两条主导直线叠加

cam = VideoCamera();             % 或 webcam
while true
    im = cam.grab();
    edges = icanny(im);
    h = Hough(edges, 'suppress', 5, 'houghThresh', 0.3);
    lines = h.lines();
    [~, k] = sort([lines.strength], 'descend');
    idisp(im);                   % 显示原图
    for i = 1:min(2, numel(k))
        lines(k(i)).plot();      % 叠加两条最强直线
    end
    drawnow;
end

预期：窗口中实时显示图像，并在其上叠加两条 strength 最大的直线；场景转动时直线随之更新。若峰抖动，增大 'suppress' 或 'houghThresh'。

关键点

  • Hough 用 $(\rho,\theta)$ 参数化把「共线点检测」变成「累加器找峰」：$u\cos\theta+v\sin\theta=\rho$，投票索引 $j=\mathrm{round}\!\left(\frac{\rho+\rho_{\max}}{2\rho_{\max}}N_\rho\right)$。
  • 累加器量化是偏差-方差权衡：粗量化合并直线，细量化分裂直线，需用 'suppress' 做非局部极大值抑制。
  • 边缘算子决定投票质量：Canny 边缘细而干净，Sobel 边缘粗而含噪，直接影响峰的尖锐度与伪峰数量。
  • 'houghThresh' 与 'suppress' 控制「报告几条线」，'interpSize' 控制「线参数多准」。
  • 本章 Hough 的输出（直线参数与强度）是第 14 章多视图几何的输入之一，服务于对应与 3D 恢复。

题目 5. 角点检测器点击展开解答 ▾

本题是第 13 章「图像特征提取」中关于兴趣点检测器的动手实验题，核心围绕结构张量 $\mathbf{A}$ 与三种角点强度函数的对比。以下按小题分步推导。

(a) 改变 $k$、$\sigma_D$、$\sigma_I$ 实验 Harris

做什么：用 icorner 在测试图像（如 castle 或 b1）上运行 Harris 检测器，分别扫描三个参数。

为什么：Harris 强度为

$$C_{\mathrm{Harris}} = \det(\mathbf{A}) - k\,[\mathrm{tr}(\mathbf{A})]^2 = \lambda_1\lambda_2 - k(\lambda_1+\lambda_2)^2$$

其中结构张量为

$$\mathbf{A} = G(\sigma_I) * \begin{bmatrix} I_u^2 & I_u I_v \\ I_u I_v & I_v^2 \end{bmatrix}$$

  • $k$ 控制「山脊」与「尖峰」的判别倾向：$k$ 越小越倾向接受边缘上的点（$\lambda_1\gg\lambda_2$ 时 $C$ 仍可能为正），$k$ 越大越只保留两个方向梯度都大的真角点。原书常取 $k=0.04$。
  • $\sigma_D$ 是求图像梯度 $I_u,I_v$ 时的微分尺度（derivative of Gaussian 的 $\sigma$），决定检测器对噪声与细节的敏感度：$\sigma_D$ 大则抑制噪声但定位变粗。
  • $\sigma_I$ 是结构张量中高斯加权 $G(\sigma_I)$ 的积分尺度，决定「邻域」大小：$\sigma_I$ 大则把邻近梯度聚合，角点响应更平滑、数量更少。

可运行代码（MATLAB，遵循原书工具箱）：

im = iread('castle_sign.jpg', 'grey', 'double');
for k = [0.02 0.04 0.06 0.10]
    c = icorner(im, 'nfeat', 200, 'suppress', 10, 'k', k);
    fprintf('k=%.2f -> %d features\n', k, length(c));
end
for sD = [1 2 3]
    c = icorner(im, 'nfeat', 200, 'suppress', 10, 'sd', sD);
    fprintf('sigmaD=%d -> %d features\n', sD, length(c));
end
for sI = [1 2 4]
    c = icorner(im, 'nfeat', 200, 'suppress', 10, 'si', sI);
    fprintf('sigmaI=%d -> %d features\n', sI, length(c));
end

预期观察：$k$ 增大 → 特征数减少（边缘点被剔除）；$\sigma_D$ 增大 → 噪声响应减少、特征数下降；$\sigma_I$ 增大 → 邻域聚合、特征数下降且分布更稀疏。原书未给出这些参数扫描的具体数值，按符号推导即可。

(b) 比较 Harris、Noble、Shi-Tomasi

做什么：三者共用同一结构张量 $\mathbf{A}$，仅强度函数不同。

为什么：

  • Harris：$C_{\mathrm{Harris}} = \lambda_1\lambda_2 - k(\lambda_1+\lambda_2)^2$，需要调 $k$。
  • Shi-Tomasi：$C_{ST} = \min(\lambda_1,\lambda_2)$，无自由参数，对弱角点更敏感，通常检测更稳定。
  • Noble：$C_{\mathrm{Noble}} = \dfrac{\lambda_1\lambda_2}{\lambda_1+\lambda_2+\epsilon}$，是 Harris 的归一化变体，对强边缘的抑制更彻底。

代码：

cH = icorner(im, 'nfeat', 200, 'suppress', 10, 'method', 'harris');
cS = icorner(im, 'nfeat', 200, 'suppress', 10, 'method', 'shitomasi');
cN = icorner(im, 'nfeat', 200, 'suppress', 10, 'method', 'noble');
idisp(im); cH.plot('r'); cS.plot('g'); cN.plot('b');

预期观察：Shi-Tomasi 与 Noble 通常给出更均匀的角点集合；Harris 在 $k$ 偏小时会保留部分边缘点。原书未给出三者特征数的具体数值。

(c) 实现 Moravec 检测器并与 Harris 比较

做什么：Moravec 是最早的角点检测器，用四个方向（水平、垂直、两对角）的 SSD（sum of squared differences）最小值作为角点强度。

为什么：Moravec 强度为

$$C_{\mathrm{Moravec}}(u,v) = \min_{d\in\{0°,45°,90°,135°\}} \sum_{(i,j)\in W} \big[I(u+i,v+j) - I(u+i+\Delta u_d, v+j+\Delta v_d)\big]^2$$

其中 $W$ 为窗口。它只考虑 4 个离散方向，因此对旋转不具不变性，且对噪声敏感——这正是 Harris 用结构张量 $\mathbf{A}$ 取代离散方向 SSD 的动机。

代码（示意）：

function C = moravec(im, win, shift)
    [h,w] = size(im);
    C = zeros(h,w);
    dirs = [0 1; 1 0; 1 1; 1 -1];
    for d = 1:4
        du = dirs(d,1); dv = dirs(d,2);
        S = zeros(h,w);
        for i = -win:win
            for j = -win:win
                a = im(max(1,min(h, (1:h)'+i)), max(1,min(w,(1:w)+j)));
                b = im(max(1,min(h, (1:h)'+i+du)), max(1,min(w,(1:w)+j+dv)));
                S = S + (a-b).^2;
            end
        end
        if d == 1, C = S; else, C = min(C, S); end
    end
end

预期观察：Moravec 在旋转后的同一场景上检测到的角点位置会漂移，而 Harris 因结构张量的各向同性加权更稳定。原书未给出 Moravec 的具体数值。

(d) 创建平滑的二阶导数 $I_{uu}$、$I_{vv}$、$I_{uv}$

做什么：用 derivative of Gaussian 对图像求二阶偏导，得到 Hessian 分量。

为什么：Hessian $\mathbf{H}=(I_{uu},I_{vv},I_{uv})$ 用于 blob 检测与尺度空间（LoG 的 DoG 近似）。平滑是为了抑制二阶导对噪声的放大。

代码：

sigma = 2;
[Du, Dv] = idogauss(sigma);          % 一阶 DoG 核
Iu = iconv(im, Du);  Iv = iconv(im, Dv);
Iuu = iconv(Iu, Du); Ivv = iconv(Iv, Dv); Iuv = iconv(Iu, Dv);
idisp(Iuu, 'plain'); idisp(Ivv, 'plain'); idisp(Iuv, 'plain');

预期观察：$I_{uu}$、$I_{vv}$ 在边缘处呈正负交替的条带；$I_{uv}$ 在角点附近响应最强。原书未给出这些二阶导图的具体数值。

关键点

  • Harris 强度 $C_{\mathrm{Harris}}=\lambda_1\lambda_2-k(\lambda_1+\lambda_2)^2$ 中，$k$ 是唯一自由参数，常取 0.04；Shi-Tomasi 用 $\min(\lambda_1,\lambda_2)$ 免去调参，Noble 用归一化形式抑制边缘。
  • 三个尺度参数分工明确：$\sigma_D$ 控制梯度平滑（抗噪 vs 定位精度），$\sigma_I$ 控制结构张量的积分邻域（聚合程度）。
  • Moravec 只用 4 个离散方向的 SSD 最小值，不具备旋转不变性；Harris 用结构张量 $\mathbf{A}$ 的各向同性高斯加权克服了这一缺陷。
  • 二阶导数 $I_{uu},I_{vv},I_{uv}$ 必须先用 derivative of Gaussian 平滑，否则噪声被二次放大；它们构成 Hessian $\mathbf{H}$，是尺度空间 blob 检测的基础。
