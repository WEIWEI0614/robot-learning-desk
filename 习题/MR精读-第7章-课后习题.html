题目 1点击展开解答 ▾

closed chain 是含一个或多个 loop 的运动链；parallel mechanism 是固定平台与动平台由多条腿连接的闭链，腿通常是开链，也可本身是闭链。

对 parallel mechanism，若给定动平台位形 \(T_{sb}\)，即给定 \(p\) 与 \(R\)，则每条腿的向量回路为

\[

d_i=p+Rb_i-a_i,

\]

其中 \(a_i\) 是 \(\{s\}\) 坐标下从 \(\{s\}\) 原点到固定平台关节 \(A_i\) 的向量，\(b_i\) 是 \(\{b\}\) 坐标下从 \(\{b\}\) 原点到动平台关节 \(B_i\) 的向量。注意 \(b_i\) 必须先用 \(R_{sb}\) 转到 \(\{s\}\) 坐标，不能直接写成 \(p+b_i-a_i\)。

于是腿长为

\[

s_i=\|d_i\|=\sqrt{d_i^Td_i}.

\]

因此 inverse kinematics 只需逐腿计算 \(d_i\) 与 \(s_i\)，通常较直接。

反过来，forward kinematics 是给定腿长 \(s_i\)，求满足

\[

s_i^2=(p+Rb_i-a_i)^T(p+Rb_i-a_i)

\]

的 \(p,R\)。这是多个非线性约束方程，可能无解或多解。例如 3×RPR 最多 6 个 FK 解，一般 6-6 Stewart-Gough platform 最多 40 个解。因此并联机构通常 IK 较直接、FK 复杂。

\[

T_{sb}=T_1(\theta)=T_2(\phi)=T_3(\psi),

\]

\[

T_1(\theta)=T_2(\phi),\qquad T_2(\phi)=T_3(\psi).

\]

题目 3点击展开解答 ▾

闭链微分约束为

\[

H_a\dot q_a+H_p\dot q_p=0.

\]

若 \(H_p\) 可逆，则

\[

\dot q_p=-H_p^{-1}H_a\dot q_a.

\]

取任一条腿 \(i\)，其 differential forward kinematics 为

\[

V_s=J_i\dot q_i.

\]

把该腿的关节速度按 actuated/passive 分块：

\[

\dot q_i=

\begin{bmatrix}\dot q_{i,a}\\ \dot q_{i,p}\end{bmatrix},

\qquad

J_i=

\begin{bmatrix}J_{i,a}&J_{i,p}\end{bmatrix}.

\]

于是

\[

V_s=J_{i,a}\dot q_{i,a}+J_{i,p}\dot q_{i,p}.

\]

注意 \(\dot q_{i,a}\) 是整体 actuated joint 速度 \(\dot q_a\) 中属于该腿的部分，\(\dot q_{i,p}\) 是整体 passive joint 速度 \(\dot q_p\) 中属于该腿的部分。利用

\[

\dot q_p=-H_p^{-1}H_a\dot q_a,

\]

可把 \(\dot q_{i,p}\) 用 \(\dot q_a\) 表示。代回得

\[

V_s=J_{i,a}\dot q_{i,a}+J_{i,p}\bigl(-H_p^{-1}H_a\dot q_a\bigr)_{i}.

\]

把所有项整理成对整体 \(\dot q_a\) 的线性映射，即

\[

V_s=J_a(q)\dot q_a.

\]

其中 \(J_a(q)\) 由两部分组成：一部分来自该腿对 actuated joints 的 \(J_{i,a}\)，另一部分来自该腿对 passive joints 的 \(J_{i,p}\) 与约束消去矩阵 \(-H_p^{-1}H_a\) 的乘积。因此 \(J_a(q)\) 依赖机构位形 \(q\)，并且只在 \(H_p\) 可逆时可直接构造。

题目 5点击展开解答 ▾

下面代码用一组对称的 \(a_i,b_i\) 构造平面 3×RPR 的腿长约束，并数值观察对称位形附近的 FK 多解与不可预测旋转。该组 \(a_i,b_i\) 是用于验证本章概念的示例，不是原书给出的具体数值。

import numpy as np
from scipy.optimize import fsolve

# 示例：固定平台三个关节 A_i 在半径 1 的圆上，间隔 120 度
a = []
for k in range(3):
    ang = 2*np.pi*k/3
    a.append(np.array([np.cos(ang), np.sin(ang)]))
a = np.array(a)

# 示例：动平台三个关节 B_i 在 body frame 中半径 0.5 的圆上，间隔 120 度
b = []
for k in range(3):
    ang = 2*np.pi*k/3
    b.append(np.array([0.5*np.cos(ang), 0.5*np.sin(ang)]))
b = np.array(b)

def leg_sq(p, phi, i):
    R = np.array([[np.cos(phi), -np.sin(phi)],
                  [np.sin(phi),  np.cos(phi)]])
    d = p + R @ b[i] - a[i]
    return d @ d

def fk_residual(x, s):
    p = x[:2]
    phi = x[2]
    return np.array([leg_sq(p, phi, i) - s[i]**2 for i in range(3)])

# 对称位形：p=0, phi=0，此时三条腿长度相同
p0 = np.array([0.0, 0.0])
phi0 = 0.0
s0 = np.array([leg_sq(p0, phi0, i) for i in range(3)])
print("symmetric leg squared lengths:", s0)

# 从对称位形出发，稍微伸长所有腿
eps = 1e-3
s_plus = s0 + eps

# 用两个不同初值求 FK，观察是否得到不同分支
x1 = fsolve(fk_residual, np.array([0.0, 0.0,  0.1]), args=(s_plus,), full_output=True)
x2 = fsolve(fk_residual, np.array([0.0, 0.0, -0.1]), args=(s_plus,), full_output=True)

print("solution branch 1: p=", x1[0][:2], "phi=", x1[0][2], "res=", x1[1]["fvec"])
print("solution branch 2: p=", x2[0][:2], "phi=", x2[0][2], "res=", x2[1]["fvec"])

预期观察：在对称位形 \(p=0,\phi=0\) 处，三条腿长度相同且尽可能短。当所有腿长同时增加一个小量 \(\varepsilon\) 时，从不同初值出发会收敛到不同的 \(\phi\) 分支，例如一个分支 \(\phi>0\)，另一个分支 \(\phi<0\)。这说明从该对称位形伸长腿时，平台可能顺时针或逆时针旋转，无法由腿长唯一预测。该现象与本章事实底座中“3×RPR 在 singular configuration 中每条腿长度相同且尽可能短；从该对称位形伸长腿时，平台可能顺时针或逆时针旋转，无法预测”一致。
