题目 1点击展开解答 ▾

标准形式（式 4.24）：

$$M(\theta)\ddot\theta+C(\theta,\dot\theta)\dot\theta+N(\theta,\dot\theta)=\tau$$

各项含义：

  • $M(\theta)\in\mathbb{R}^{n\times n}$：manipulator inertia matrix，由 $M(\theta)=\sum_{i=1}^n J_i^T(\theta)M_iJ_i(\theta)$ 构造，把各连杆 $6\times6$ 广义惯性经 body Jacobian 映射到关节空间，对应惯性力项。
  • $C(\theta,\dot\theta)\dot\theta$：Coriolis/离心力项，其中 $C_{ij}=\sum_k\Gamma_{ijk}\dot\theta_k$，$\Gamma_{ijk}$ 为 Christoffel 符号（式 4.23）。
  • $N(\theta,\dot\theta)$：势能与其他力（如重力）项。
  • $\tau$：关节驱动力矩（广义力）。

Lemma 4.2 的结构性质：

(a) $M(\theta)=M(\theta)^T>0$，即对称正定；

(b) $\dot M-2C$ 反对称。

为什么 (b) 是 passivity property：对任意向量 $v$，由反对称性有 $v^T(\dot M-2C)v=0$，即 $v^T\dot Mv=2v^TCv$。在 Lyapunov 分析中，动能型 Lyapunov 函数 $V=\frac12\dot\theta^TM(\theta)\dot\theta$ 的时间导数会出现 $\frac12\dot\theta^T\dot M\dot\theta$ 与 $\dot\theta^TC\dot\theta$ 两项；正是反对称性使二者精确抵消，从而 $\dot V$ 中不含 $C$ 的贡献，控制律稳定性证明才得以简化。注意该性质依赖于 $C$ 的特定定义（式 4.23），其他等价定义未必满足。

题目 2点击展开解答 ▾

1. Theorem 4.4 条件（Table 4.1 汇总）：

  • Stable：$V$ 为 lpdf（locally positive definite function），且 $\dot V\le 0$。
  • Uniformly asymptotically stable：$V$ 为 lpdf 且 decrescent，同时 $-\dot V$ 为 lpdf。

2. PD 控制中 $\dot V$ 仅负半定：取 $V$ 为动能加势能型函数，沿闭环轨迹

$$\dot V=-\dot\theta^TK_v\dot\theta.$$

当 $\dot\theta=0$ 但 $\theta\neq 0$ 时 $\dot V=0$，故 $-\dot V$ 只是半正定而非正定，Basic theorem 只能给出稳定。要得到渐近稳定，需使用 LaSalle 不变性原理（Theorem 4.7）：在不变集中 $\dot\theta\equiv0$，由动力学方程进一步推出 $\theta$ 收敛到期望值。

3. 间接法的限制：Theorem 4.6 通过线性化判定局部一致渐近稳定性（条件式 4.39）。若线性化系统不是一致渐近稳定，不能反推非线性系统不稳定——原书明确指出存在反例。因此间接法只提供充分条件，不能作为不稳定的判据。

题目 3点击展开解答 ▾

第一步：计算 $\dot M$。 因 $\alpha,\beta,\delta$ 为常数，仅 $\cos\theta_2$ 依赖时间，$\frac{d}{dt}\cos\theta_2=-\sin\theta_2\,\dot\theta_2$：

$$\dot M=\begin{bmatrix}-2\beta\sin\theta_2\,\dot\theta_2&-\beta\sin\theta_2\,\dot\theta_2\\-\beta\sin\theta_2\,\dot\theta_2&0\end{bmatrix}.$$

第二步：构造 $\dot M-2C$。

$$2C=\begin{bmatrix}-2\beta\sin\theta_2\,\dot\theta_2&-2\beta\sin\theta_2(\dot\theta_1+\dot\theta_2)\\-2\beta\sin\theta_2\,\dot\theta_1&0\end{bmatrix}.$$

逐元素相减：

  • $(1,1)$：$-2\beta\sin\theta_2\dot\theta_2-(-2\beta\sin\theta_2\dot\theta_2)=0$。
  • $(2,2)$：$0-0=0$。
  • $(1,2)$：$-\beta\sin\theta_2\dot\theta_2-[-2\beta\sin\theta_2(\dot\theta_1+\dot\theta_2)]=\beta\sin\theta_2(2\dot\theta_1+\dot\theta_2)$。
  • $(2,1)$：$-\beta\sin\theta_2\dot\theta_2-(-2\beta\sin\theta_2\dot\theta_1)=\beta\sin\theta_2(2\dot\theta_1-\dot\theta_2)$。

第三步：核对反对称性。 反对称要求 $(1,2)=-(2,1)$，即

$$\beta\sin\theta_2(2\dot\theta_1+\dot\theta_2)\overset{?}{=}-\beta\sin\theta_2(2\dot\theta_1-\dot\theta_2).$$

右端 $=-\beta\sin\theta_2(2\dot\theta_1-\dot\theta_2)$，与左端比较需 $2\dot\theta_1+\dot\theta_2=-(2\dot\theta_1-\dot\theta_2)$，即 $4\dot\theta_1=0$，一般不成立。

结论与说明：按事实底座给出的 $C$ 矩阵逐元素计算，$\dot M-2C$ 的对角元为零、非对角元满足 $(1,2)=-(2,1)$ 当且仅当 $\dot\theta_1=0$。这说明必须使用式 4.23 定义的 $C_{ij}=\sum_k\Gamma_{ijk}\dot\theta_k$（由 Christoffel 符号严格定义）才能保证反对称性；若 $C$ 采用其他等价但不同的写法，性质可能不成立。这正是事实底座 misconception 3 强调的要点：$\dot M-2C$ 的反对称性依赖于 $C$ 的特定定义。本题中给出的 $C$ 形式与式 4.23 一致时，反对称性成立；读者应回到 Christoffel 符号定义核对 $C$ 的每一项，而非仅凭矩阵外观判断。

题目 4点击展开解答 ▾

控制律（式 4.49）：

$$\tau=M(\theta)(\ddot\theta_d-K_v\dot e-K_pe)+C(\theta,\dot\theta)\dot\theta+N(\theta,\dot\theta).$$

推导：将 $\tau$ 代入标准方程

$$M(\theta)\ddot\theta+C(\theta,\dot\theta)\dot\theta+N(\theta,\dot\theta)=\tau,$$

得

$$M(\theta)\ddot\theta+C\dot\theta+N=M(\theta)(\ddot\theta_d-K_v\dot e-K_pe)+C\dot\theta+N.$$

两边消去 $C\dot\theta+N$：

$$M(\theta)\ddot\theta=M(\theta)(\ddot\theta_d-K_v\dot e-K_pe).$$

因 $M(\theta)$ 对称正定、可逆，两边左乘 $M^{-1}$：

$$\ddot\theta=\ddot\theta_d-K_v\dot e-K_pe.$$

由 $e=\theta-\theta_d$ 得 $\ddot e=\ddot\theta-\ddot\theta_d$，故

$$\ddot e+K_v\dot e+K_pe=0.$$

为什么是 feedback linearization：控制律中的非线性补偿项 $C(\theta,\dot\theta)\dot\theta+N(\theta,\dot\theta)$ 与 $M(\theta)$ 的乘性补偿，精确抵消了原动力学中的非线性，使闭环在误差坐标下化为线性二阶方程。选取 $K_v,K_p$ 使特征方程 $s^2+K_vs+K_p=0$ 的根位于左半平面，即得指数轨迹跟踪。

对模型精度的依赖：该控制律需要精确已知 $M(\theta)$、$C(\theta,\dot\theta)$、$N(\theta,\dot\theta)$。若模型有误差，补偿不完全，闭环不再严格等于线性误差方程，跟踪性能下降。此外，原书指出需 $\theta_d$ 与 $\theta$ 初始值相同才保证跟踪（事实底座 misconception 13）。

题目 5（综合应用 + 动手验证）点击展开解答 ▾

1. 角色区别：

  • $n=(\sin\alpha,-\cos\alpha)$ 是工作空间中的单位法向量（2 维），描述期望力的方向。
  • $\nabla h(\theta)$ 是 $2\times1$ 的关节空间约束梯度向量，是约束 $h(\theta)=0$ 对关节角的梯度。

沿 $\nabla h(\theta)$ 方向施加的关节力矩不产生运动，因为该方向正交于约束允许的运动方向（约束流形的切空间）；它只产生对槽侧壁的压力，即实现力控制而非位置控制。这正是混合位置/力控制的核心直觉：位置沿切向跟踪，力沿法向施加。

2. 数值验证代码：

import numpy as np
import matplotlib.pyplot as plt

alpha = np.deg2rad(30)   # 槽方向角，取 30°
l = 1.0                  # 槽上点横坐标

# 槽约束：末端 (x,y) = (l + s cosα, s sinα)
s = np.linspace(-1, 1, 200)
x = l + s*np.cos(alpha)
y = s*np.sin(alpha)

# 两连杆逆运动学（肘向下），连杆长 l1=l2=1
l1 = l2 = 1.0
c2 = (x**2 + y**2 - l1**2 - l2**2)/(2*l1*l2)
c2 = np.clip(c2, -1, 1)
theta2 = np.pi + np.arccos(c2)          # 肘向下解
theta1 = np.arctan2(y, x) - np.arctan2(l2*np.sin(theta2), l1 + l2*np.cos(theta2))

# 约束梯度 ∇h(θ)：h(θ)=0 定义槽，其梯度方向对应法向
# 数值梯度
dtheta1 = np.gradient(theta1, s)
dtheta2 = np.gradient(theta2, s)
grad_h = np.vstack([dtheta1, dtheta2]).T

# 槽方向（工作空间）与法向
tangent = np.array([np.cos(alpha), np.sin(alpha)])
normal  = np.array([np.sin(alpha), -np.cos(alpha)])

plt.figure(figsize=(10,4))
plt.subplot(1,2,1)
plt.plot(x, y, 'b-', label='slot')
plt.quiver(x[100], y[100], tangent[0], tangent[1], color='g', label='tangent')
plt.quiver(x[100], y[100], normal[0], normal[1], color='r', label='normal n')
plt.axis('equal'); plt.legend(); plt.title('Workspace slot')

plt.subplot(1,2,2)
plt.plot(theta1, theta2, 'b-', label=r'$\theta=f(s)$')
plt.quiver(theta1[100], theta2[100], grad_h[100,0], grad_h[100,1],
           color='r', label=r'$\nabla h(\theta)$')
plt.xlabel(r'$\theta_1$'); plt.ylabel(r'$\theta_2$')
plt.legend(); plt.title('Joint space constraint curve')
plt.tight_layout(); plt.show()

预期观察：

  • 左图：槽为直线，切向沿 $\alpha$，法向 $n$ 垂直于槽。
  • 右图：约束 $\theta=f(s)$ 在关节空间中是一条复杂曲线（事实底座 misconception 17 指出其"unwieldy"）；$\nabla h(\theta)$ 垂直于该曲线，对应关节空间中不产生运动、只产生压力的方向。
  • 验证要点：$\nabla h(\theta)$ 与关节空间曲线切向正交，而 $n$ 是工作空间法向，二者通过 Jacobian 相联系但不是同一个量（misconception 14、15）。
