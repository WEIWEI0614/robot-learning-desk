题目 1点击展开解答 ▾

1. Twist 与 wrench 的表示

本章所有 twists 与 wrenches 均表达在 space frame。三维空间中：

\[

V=(\omega,v)\in\mathbb{R}^6,\qquad F=(m,f)\in\mathbb{R}^6

\]

其中 \(\omega\) 为 angular velocity，\(v\) 为 linear velocity；\(m\) 为 moment，\(f\) 为 force。

平面情形下：

\[

V=(\omega_z,v_x,v_y),\qquad F=(m_z,f_x,f_y)

\]

2. 接触 wrench

单位法向力对应的 spatial contact wrench 为

\[

F=([p_A]\hat{n},\hat{n})=(p_A\times \hat{n},\hat{n})

\]

其中 \([p]\) 为 skew-symmetric matrix。注意这里用的是 body A 上的接触点 \(p_A\)。

3. 法线方向约定与不等式符号

本章约定 \(\hat{n}\) 的正方向指向 body A 内部。在这个约定下，两体相互不可穿透要求

\[

F^T(V_A-V_B)\ge 0

\]

若把 \(\hat{n}\) 反向，则 \(F\) 整体变号，不等式方向也随之翻转，contact label（R/S/B）的分类会全部出错。因此法线方向不能随意反。

题目 2点击展开解答 ▾

1. 三个接触标签

本章接触标签为：

  • R = rolling / sticking；
  • S = sliding；
  • B = breaking free。

contact mode 是各接触标签的 concatenation，例如 RR、SB、BS、BB、RRR、SlR 等。

2. Impenetrability 与 active constraint

对每个接触，

\[

F^T(V_A-V_B)\ge 0

\]

当

\[

F^T(V_A-V_B)=0

\]

时，该约束为 active constraint。

进一步分类：

  • 若 active 且 \(\dot p_A=\dot p_B\)，则为 rolling/sticking（R）；
  • 若 active 但不 rolling，则为 sliding（S）；
  • 若严格不等式成立，则为 breaking free（B）。

3. 说法判断

该说法不正确。本章的 rolling contact 定义为两体在接触点相对速度为零，即

\[

\dot p_A=v_A+[\omega_A]p_A=v_B+[\omega_B]p_B=\dot p_B

\]

这包含了 sticking（相对静止、无相对旋转）的情形。把 rolling 只理解成“轮子滚动”会漏掉 sticking，从而误判 contact label。

题目 3点击展开解答 ▾

1. 计算接触 wrench

由

\[

F=([p_A]\hat{n},\hat{n})=(p_A\times \hat{n},\hat{n})

\]

代入 \(p_A=[1\ 2\ 0]^T\)，\(\hat{n}=[0\ 1\ 0]^T\)：

\[

p_A\times \hat{n}=

\begin{vmatrix}

\mathbf{i} & \mathbf{j} & \mathbf{k}\\

1 & 2 & 0\\

0 & 1 & 0

\end{vmatrix}

=(0,\ 0,\ 1)

\]

因此

\[

F=[0\ 0\ 1\ 0\ 1\ 0]^T

\]

即 moment 部分为 \((0,0,1)\)，force 部分为 \((0,1,0)\)。

2. Roll-slide 条件

active constraint 要求 \(F^T(V_A-V_B)=0\)。将 \(F=(0,0,1,0,1,0)\) 与 \(V_A-V_B=(\omega_{Ax}-\omega_{Bx},\omega_{Ay}-\omega_{By},\omega_{Az}-\omega_{Bz},v_{Ax}-v_{Bx},v_{Ay}-v_{By},v_{Az}-v_{Bz})\) 做内积：

\[

(\omega_{Az}-\omega_{Bz})+(v_{Ay}-v_{By})=0

\]

即

\[

\omega_{Az}-\omega_{Bz}+v_{Ay}-v_{By}=0

\]

这就是 roll-slide 条件。

3. B 静止且 A 限制在 \(z=0\) 平面

B 静止意味着 \(V_B=0\)。A 限制在 \(z=0\) 平面，则

\[

V_A=[0\ 0\ \omega_{Az}\ v_{Ax}\ v_{Ay}\ 0]^T

\]

代入 roll-slide 条件：

\[

\omega_{Az}+v_{Ay}=0

\]

即

\[

v_{Ay}+\omega_{Az}=0

\]

Rolling 条件还需 \(\dot p_A=\dot p_B=0\)。由 Example 12.2 的 rolling 条件 (12.10)–(12.12)，在平面限制下化为：

\[

v_{Ax}-2\omega_{Az}=0,\qquad v_{Ay}+\omega_{Az}=0

\]

其中第二式与 roll-slide 条件一致，第一式是额外的 rolling 约束。

题目 4点击展开解答 ▾

1. 半空间约束

平面 twist 写为 \(V=(\omega_z,v_x,v_y)\)。对每个接触 \(F_i=(m_z,f_x,f_y)\)，约束为

\[

F_i^T V\ge 0

\]

即

\[

m_z\omega_z+f_x v_x+f_y v_y\ge 0

\]

代入：

  • \(F_1=(-2,0,1)\)：

\[

-2\omega_{Az}+v_{Ay}\ge 0

\]

即

\[

v_{Ay}-2\omega_{Az}\ge 0

\]

  • \(F_2=(1,-1,0)\)：

\[

\omega_{Az}-v_{Ax}\ge 0

\]

即

\[

-v_{Ax}+\omega_{Az}\ge 0

\]

  • \(F_3=(1,1,0)\)：

\[

\omega_{Az}+v_{Ax}\ge 0

\]

即

\[

v_{Ax}+\omega_{Az}\ge 0

\]

2. 是否正张成 \(R^3\)

三个向量 \(F_1,F_2,F_3\) 位于 \(R^3\) 中。要正张成 \(R^3\)，需要它们线性无关且原点位于其凸包内部（等价地，存在正系数组合为零）。

先看线性无关性。设

\[

\alpha_1 F_1+\alpha_2 F_2+\alpha_3 F_3=0

\]

分量形式：

\[

-2\alpha_1+\alpha_2+\alpha_3=0

\]

\[

-\alpha_2+\alpha_3=0

\]

\[

\alpha_1=0

\]

由第三式 \(\alpha_1=0\)，第二式 \(\alpha_2=\alpha_3\)，第一式 \(0+\alpha_2+\alpha_3=2\alpha_2=0\)，故 \(\alpha_2=\alpha_3=0\)。所以三向量线性无关。

再看是否存在正系数组合为零。由上面可知唯一线性组合为零的系数全为零，因此不存在非零正组合为零。这意味着原点不在三向量凸包内部，三向量不能正张成 \(R^3\)。

因此这三个 wrenches 不构成平面 first-order form closure。

3. 平面 form closure 的最少接触数

平面 first-order form closure 要求 contact wrenches 正张成 \(R^3\)。\(R^n\) 可由 \(n+1\) 个向量正张成但不少于此，故平面 \(n=3\) 至少需要 \(3+1=4\) 个点接触。本题只有 3 个接触，数量上也不足。

题目 5点击展开解答 ▾

1. 静止时 RR 不可行

静止时 block 需平衡重力，所需 wrench 为

\[

F_{\text{ext}}=(0,0,mg)

\]

RR 模式要求存在非负系数 \(k_1,k_2,k_3\ge 0\) 使得

\[

k_1F_1+k_2F_2+k_3F_3=(0,0,mg)

\]

但根据 Example 12.9，\((0,0,mg)\) 不在由 \(F_1,F_2,F_3\) 正张成的 composite wrench cone 中，因此 RR 不可行。

2. fingers 以 \(2g\) 向左加速时 RR 可行

若 fingers 以 \(2g\) 向左加速，block 受到惯性力。方程 (12.33) 为

\[

k_1F_1+k_2F_2+k_3F_3+(0,0,-mg)=(0,ma_x,0)

\]

当 \(a_x=-2g\) 时，右边为 \((0,-2mg,0)\)，故

\[

k_1F_1+k_2F_2+k_3F_3=(0,-2mg,mg)

\]

该总 wrench 落在 composite wrench cone 内，因此存在非负 \(k_i\)，RR 可行。非负 \(k_i\) 要求

\[

-5g\le a_x\le -g

\]

\(a_x=-2g\) 满足此范围。

3. 可运行代码与预期观察

import numpy as np
from scipy.optimize import linprog

# 基接触 wrenches (m_z, f_x, f_y)
F1 = np.array([-4, -1,  1]) / np.sqrt(2)
F2 = np.array([-2,  1,  1]) / np.sqrt(2)
F3 = np.array([ 1, -1,  0])

# 列向量构成矩阵 A，求 k >= 0 使 A k = target
A = np.column_stack([F1, F2, F3])

def in_cone(target, A):
    # 变量 k1,k2,k3 >= 0，约束 A k = target
    # linprog 默认最小化，目标设为零向量即可
    c = np.zeros(A.shape[1])
    res = linprog(c, A_eq=A, b_eq=target,
                  bounds=[(0, None)]*A.shape[1],
                  method='highs')
    return res.success, res.x if res.success else None

mg = 1.0  # 归一化，取 mg = 1

# 静止所需 wrench
target_static = np.array([0, 0, mg])
ok_static, k_static = in_cone(target_static, A)
print("static (0,0,mg) in cone?", ok_static)
if ok_static:
    print("k =", k_static)

# 2g 向左加速所需总 wrench
target_acc = np.array([0, -2*mg, mg])
ok_acc, k_acc = in_cone(target_acc, A)
print("accelerating (0,-2mg,mg) in cone?", ok_acc)
if ok_acc:
    print("k =", k_acc)

预期观察：

  • static (0,0,mg) in cone? 输出 False，说明静止 RR 不可行。
  • accelerating (0,-2mg,mg) in cone? 输出 True，并给出一组非负 \(k_1,k_2,k_3\)，说明以 \(2g\) 向左加速时 RR 可行。

这验证了 dynamic grasp 不是静力平衡：静止时不可行的接触模式，在惯性力作用下可能变为可行。
