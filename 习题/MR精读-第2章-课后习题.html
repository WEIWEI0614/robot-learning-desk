题目 1点击展开解答 ▾

本章的定义是：

  • Configuration：机器人所有点位置的一次完整指定。
  • C-space：所有 possible configurations 的集合。
  • dof：表示 configuration 所需的最少实值坐标数。

“给每个关节一个角度值”不一定等于完整指定 configuration，原因是：

  1. 关节变量只是机器人内部连接关系的一种坐标描述，不一定能唯一确定机器人所有点的位置；
  2. 对 closed-chain 机构，关节变量之间可能存在 holonomic constraints，不能独立自由选取；
  3. 对同一 C-space，可以选择不同坐标表示，dof 是 C-space 的维数，而不是某个特定坐标卡的变量个数；
  4. 若存在 nonholonomic constraints，它限制的是可行速度，而不是直接减少 reachable C-space 的维度。

刚体自由度结论为：

\[

\text{spatial rigid body}=6,\qquad \text{planar rigid body}=3.

\]

对应典型 C-space 拓扑为：

\[

\text{spatial rigid body}: R^3\times S^2\times S^1,

\]

\[

\text{planar rigid body}: R^2\times S^1.

\]

其中 \(R^3\) 或 \(R^2\) 表示位置，\(S^2\) 表示 spatial 情形下的方向单位球面，\(S^1\) 表示平面情形下的朝向角或 spatial 情形下的自转。

题目 2点击展开解答 ▾

Grübler’s formula 为：

\[

\text{dof}=m(N-1-J)+\sum_{i=1}^J f_i.

\]

各符号含义：

  • \(N\)：links 数，且 ground 也算一个 link；
  • \(J\)：joints 数；
  • \(m=3\) 用于 planar mechanisms，\(m=6\) 用于 spatial mechanisms；
  • joint \(i\) 有 \(f_i\) 个 freedoms；
  • joint \(i\) 有 \(c_i\) 个 constraints，且

\[

f_i+c_i=m,\qquad c_i=m-f_i.

\]

对 planar four-bar linkage：

  • planar，所以 \(m=3\)；
  • \(N=4\)；
  • \(J=4\)；
  • 每个 joint 都是 revolute joint，因此每个 \(f_i=1\)。

代入：

\[

\text{dof}=3(4-1-4)+\sum_{i=1}^4 1

=3(-1)+4

=1.

\]

所以 planar four-bar linkage 的 dof 为 \(1\)。它是一个单自由度闭链机构。

题目 3点击展开解答 ▾

推导如下。

先看 \(N\) 个 links，其中 ground 固定，因此只有 \(N-1\) 个 link 可动。若暂时没有 joints 约束，每个可动刚体有 \(m\) 个 freedoms，所以总 freedoms 为：

\[

m(N-1).

\]

每个 joint \(i\) 提供 \(f_i\) 个 freedoms，同时施加 \(c_i\) 个 constraints，并且：

\[

f_i+c_i=m.

\]

因此：

\[

c_i=m-f_i.

\]

所有 joints 的总 constraints 为：

\[

\sum_{i=1}^J c_i

=

\sum_{i=1}^J (m-f_i).

\]

若这些 constraints 独立，则：

\[

\text{dof}

=

\text{sum of freedoms of bodies}

-

\text{number of independent constraints}.

\]

于是：

\[

\text{dof}

=

m(N-1)-\sum_{i=1}^J c_i.

\]

代入 \(c_i=m-f_i\)：

\[

\text{dof}

=

m(N-1)-\sum_{i=1}^J (m-f_i).

\]

展开：

\[

\text{dof}

=

m(N-1)-mJ+\sum_{i=1}^J f_i.

\]

整理得：

\[

\text{dof}

=

m(N-1-J)+\sum_{i=1}^J f_i.

\]

其中 \(N-1\) 来自 ground 固定，只有 \(N-1\) 个 link 可作为自由刚体；加上 \(\sum f_i\) 是因为每个 joint 并不是完全约束，而是保留 \(f_i\) 个自由度。

题目 4点击展开解答 ▾

对 parallelogram linkage，若按通常数法：

  • planar，所以 \(m=3\)；
  • \(N=5\)；
  • \(J=6\)；
  • 每个 joint 的 \(f_i=1\)。

代入 Grübler：

\[

\text{dof}

=

3(5-1-6)+\sum_{i=1}^6 1

=

3(-2)+6

=

0.

\]

公式给出 \(0\) dof，似乎说明它是刚性结构。

但实际 parallelogram linkage 仍可动，具有 \(1\) dof。原因是：这些 joints 提供的 constraints 并不 independent，存在 redundant constraints。Grübler 公式默认 constraints independent，因此在这种非 generic 情况下会给出错误结果。

修正数法为：

  • \(N=4\)；
  • \(J=4\)；
  • 每个 \(f_i=1\)。

于是：

\[

\text{dof}

=

3(4-1-4)+\sum_{i=1}^4 1

=

3(-1)+4

=

1.

\]

这与实际可动性一致。

该例子说明：dof 不是简单地“变量数减方程数”，而应是“变量数减 independent equations 数”。当存在 redundant constraints 时，约束方程数不能直接当作独立约束数，Grübler 公式只在 generic 情况下成立。

题目 5点击展开解答 ▾
  1. 对 planar 2R robot arm，两个关节都是 revolute joint，每个关节角取值于 \(S^1\)。因此：

\[

\text{C-space}=S^1\times S^1=T^2.

\]

  1. 若把该 2R arm 安装在一个 planar rigid body 上，planar rigid body 的 C-space 为：

\[

R^2\times S^1.

\]

再叠加 2R arm 的 \(T^2\)，整体为：

\[

R^2\times S^1\times T^2

=

R^2\times T^3.

\]

  1. 可运行代码如下：
import numpy as np
import matplotlib.pyplot as plt

# 离散采样两个关节角
theta1 = np.linspace(0, 2*np.pi, 60, endpoint=False)
theta2 = np.linspace(0, 2*np.pi, 60, endpoint=False)

# 构造 C-space 网格
T1, T2 = np.meshgrid(theta1, theta2)

# 观察边界：theta=0 与 theta=2*pi 应视为同一点
fig, ax = plt.subplots(figsize=(6, 6))
ax.scatter(T1.ravel(), T2.ravel(), s=2)

ax.set_xlabel(r"$\theta_1$")
ax.set_ylabel(r"$\theta_2$")
ax.set_title(r"Discrete samples of 2R arm C-space: $T^2=S^1\times S^1$")
ax.set_xticks([0, np.pi, 2*np.pi])
ax.set_yticks([0, np.pi, 2*np.pi])
ax.set_xticklabels(["0", r"$\pi$", r"$2\pi$"])
ax.set_yticklabels(["0", r"$\pi$", r"$2\pi$"])
plt.show()

预期观察：

  • 采样点填满一个正方形区域；
  • 但该正方形的左边界 \(\theta_1=0\) 与右边界 \(\theta_1=2\pi\) 应视为同一条边；
  • 下边界 \(\theta_2=0\) 与上边界 \(\theta_2=2\pi\) 也应视为同一条边；
  • 因此这个“正方形”的上下边粘合、左右边粘合后得到 torus \(T^2\)，而不是普通平面 \(R^2\)。
  1. \(T^2\) 不能简单等同于 \(R^2\)，因为拓扑不同：
  • 在 \(R^2\) 中，直线可以一直延伸，不会自动回到起点；
  • 在 \(S^1\) 中，角度增加 \(2\pi\) 后回到同一构型；
  • 因此 \(T^2=S^1\times S^1\) 具有周期性闭合结构；
  • 例如在 2R arm 中，\(\theta_1=0\) 与 \(\theta_1=2\pi\) 表示同一个 configuration，\(\theta_2=0\) 与 \(\theta_2=2\pi\) 也表示同一个 configuration。

所以 \(T^2\) 与 \(R^2\) 虽然局部都可用两个坐标描述，但整体拓扑不同。
